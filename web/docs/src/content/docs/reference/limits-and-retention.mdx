Every number in Lodekit's services, collected on one page. Most of them are
platform settings you can tune in the dashboard under **Settings → Services**
— the *Setting* column names the key (some sit behind the **Advanced**
toggle). Rows marked **fixed** are hard limits that can't be changed.

## Scoped API

Every SDK call except file bodies rides the scoped API, whose request body
caps at **100 kb** (fixed). That bounds **kv-store** values and task payloads.
File
bytes stream outside this cap and have no size limit.

## Relational Data Store

| Limit | Value | Setting |
|---|---|---|
| Retention | None — the **db-store** is the system of record | — |
| Request size | 100 kb per request | fixed |

## Key-Value Data Store

| Limit | Value | Setting |
|---|---|---|
| Key length | ≤ 512 characters | fixed |
| Value size | ≤ 100 kb per request | fixed |
| List page size | Default 1000, max 1000 | `kv.list_limit` |
| Expiry sweep | Every 60 seconds | `kv.sweep_interval` |
| Change events | Kept 7 days | fixed |

## File Store

| Limit | Value | Setting |
|---|---|---|
| File body | No size cap — it's your disk | — |
| Slug | Lowercase letters, digits, hyphens; 1–128 characters | fixed |
| Title | ≤ 512 characters | fixed |
| Metadata | ≤ 4 KB of JSON | fixed |
| List page size | Default 100, max 1000 | `files.list_limit` |
| Expiry sweep | Every 60 seconds | `files.sweep_interval` |
| Change events | Kept 7 days | fixed |

## Event Store

| Limit | Value | Setting |
|---|---|---|
| Payload size | ≤ 8 KB | fixed |
| Type | Lowercase letters, digits, hyphens; ≤ 128 characters | fixed |
| Retention | 30 days / 50,000 events | `events.retention_age` / `events.retention_max_rows` |
| Per-event `ttl` | Optional, up to 30 days | fixed |
| Change-feed events | Kept 7 days | fixed |

## Tasks

| Limit | Value | Setting |
|---|---|---|
| Retries | Default 3 (0–20 per task) | `tasks.default_retries` |
| Timeout per attempt | 5 minutes | `tasks.default_timeout` |
| Catch-up window | 1 hour | `tasks.default_catch_up` |
| Retry backoff | 30s × 2ⁿ, capped at 10 minutes | `tasks.backoff_base` / `tasks.backoff_cap` |
| Schedule grace | 30 seconds | `tasks.schedule_grace` |
| Minimum interval | `every` of at least 1 minute | `tasks.min_every` |
| Run history | Last 100 runs or 30 days per task (whichever keeps more) | `tasks.run_retention_count` / `tasks.run_retention_age` |
| Runs list page size | Default 50, max 200 | `tasks.list_limit` |
| Payload size | ≤ 100 kb per request | fixed |
| Dedupe key | 1–256 characters | fixed |
| Task name | Lowercase letters, digits, hyphens; ≤ 128 characters | fixed |

## Gateways

| Limit | Value | Setting |
|---|---|---|
| Request timeout | Default 10 seconds (1 s – 60 s) | `gateways.default_timeout` |
| Timeout hard cap | 60 seconds | fixed |
| Rate limit | 60 requests/minute per gateway | `gateways.default_rate` |
| Concurrency | 4 parallel requests per gateway (1–32) | `gateways.default_concurrency` |
| Response size | ≤ 10,000,000 bytes — larger responses are aborted | `gateways.max_response_bytes` |
| Body capture in logs | Off | `gateways.capture_bodies` |
| Breaker threshold | 5 consecutive failures to open | `gateways.breaker_failure_threshold` (Advanced) |
| Breaker cooldown | 30 seconds | `gateways.breaker_cooldown` (Advanced) |
| `Retry-After` pause | Capped at 15 minutes | fixed |

A gateway's manifest can override `rate`, `concurrency`, and `timeout_ms` for
that gateway alone — see [Gateways](/services/gateways/).

## Secret Store

| Limit | Value | Setting |
|---|---|---|
| Value size | ≤ 4 KB | fixed |
| Slot keys | snake_case, ≤ 64 characters | fixed |

## Settings

| Limit | Value | Setting |
|---|---|---|
| Field types | `boolean`, `string`, `number`, `select`, `duration` | — |
| Keys | snake_case, ≤ 64 characters | fixed |
| Label / description | ≤ 80 / ≤ 240 characters | fixed |
| String values | ≤ 4096 characters | fixed |

## Log Store

| Limit | Value | Setting |
|---|---|---|
| Retention | 7 days / 200,000 records | `logs.retention_age` / `logs.retention_max_rows` |
| Message length | ≤ 8192 characters | fixed |
| Query page size | Default 100, max 1000 | `logs.list_limit` |
| Text log files | Kept 7 days | fixed |
