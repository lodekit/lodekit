Every Lodekit app is styled from one shared theme, so everything feels like one
product. Out of the box that theme is **shadcn** — the familiar neutral look of
stock shadcn/ui — and it applies to the dashboard and every app with zero
configuration. Prefer something with more character? The **lodekit** theme (warm
parchment and ink) and a handful of popular ports (Dracula, Catppuccin, Nord,
Rosé Pine) ship alongside it.

## The Themes page

Open **Themes** in the dashboard for the gallery: every theme with light and dark
previews. From a theme's card you can:

- **Use everywhere** — the whole platform switches, live. No reloads.
- **Assign to app…** — one app gets its own look; everything else keeps the
  global choice.
- **Duplicate** — copy any theme into an editable one of your own.

Every theme carries both a light and a dark palette. Which one you see is the
**Appearance** setting (system, light, or dark) — switching themes never touches
your mode.

## The editor

Open a theme to edit it. Vendored themes are read-only — duplicate one to make it
yours. Colors are grouped into roles (brand, background, surface, muted, border),
with every underlying token one click deeper. Below them: fonts, the icon set,
radius and density, and **Effects** — elevation, easing, and body weight, so a
theme can be flat and calm or stock and shadowed. The preview shows every
component live, or a real app in an iframe, before you save.

## Files, if you want them

Themes are plain CSS files in your Lodekit folder — `themes/<name>.css` — and the
selection lives next to them in `themes/config.json`:

```json title="~/Documents/Lodekit/themes/config.json"
{ "global": "dracula", "apps": { "garden": "lodekit" } }
```

A theme file redefines **tokens**: colors like `--primary` and `--background`,
shape like `--radius`, fonts, the icon set, and the physics fields
(`--font-weight-body`, `--default-transition-timing-function`, the `--shadow-*`
scale). Tokens are the stable, supported surface — you *can* write any CSS in a
theme, but only tokens are promised to keep working as Lodekit's components
evolve. Save a file and the new look applies everywhere within a beat.

You don't have to hand-pick values yourself. Your agent knows the format — ask it
to "make everything warmer and rounder" or "give the garden app a green theme"
and it writes the theme for you.
