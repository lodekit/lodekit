# db-store v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the db-store service (per-app relational database on drizzle) with the unified migration engine, the `_lodekit_*` → `_` rename, SDK `createDb`, MCP read tools, skill/context updates, and the Greenhouse refactor — per `docs/specs/2026-07-09-db-store-design.md`.

**Architecture:** One migration engine (transactional applier + `_migrations` ledger) with two modes: ordered checked-in migration files for every internal schema (per-app service tables and the four platform DBs), and drizzle-kit push-diff for app-declared tables (additive auto-applies at worker boot over the manifest channel; destructive gates with a `schema-state` event). Apps author schemas in `src/db.ts` (drizzle `sqliteTable`) and query through `createDb(schema)` — a drizzle sqlite-proxy instance whose driver is HTTP against the scoped API; workers never touch sqlite.

**Tech Stack:** better-sqlite3 (existing), drizzle-orm 0.45.x (`drizzle-orm/sqlite-core`, `drizzle-orm/sqlite-proxy`), drizzle-kit 0.31.x (`drizzle-kit/api`, in-process only — never the CLI), Hono + zod (existing route conventions), vitest.

## Global Constraints

- Spec: `docs/specs/2026-07-09-db-store-design.md`. Read it before starting any task.
- Catalog name is **`db-store`**; SDK handle is **`db`**; mount is `/api/apps/:appId/db-store/`.
- Service tables use the bare-`_` prefix: `_kv`, `_files`, `_task_defs`, `_task_runs`, `_setting_defs`, `_setting_values`, `_secret_slots`, `_schema`, `_migrations`. The string `_lodekit_` must not survive in `packages/` source (only in migration 001's rename-from names and tests that build legacy shapes).
- User tables are physically named exactly as declared; names starting with `_` or `sqlite_` are rejected at schema push.
- drizzle-kit is used **only** via `import("drizzle-kit/api")` — no CLI invocation, no `drizzle.config.ts` anywhere.
- Commit style: repo convention, no `Co-Authored-By` trailers (CLAUDE.md). Commit directly on the current `service` branch.
- Run tests with `pnpm --filter @lodekit/runtime test -- <file>` (the package scripts are `vitest run`, so pass only the file); full suite is `pnpm test` from the repo root.
- Never run `pnpm install` with CWD inside `manager/` (CLAUDE.md gotcha). Install from the repo root.
- All new runtime code follows the kv-store v2 module convention: one file in `packages/runtime/src/services/`, chained Hono router (for `hc` type inference), `onError` → 400 with `{ error }`, zod + `validationHook` at the boundary.

```ts
// The migration engine's core applier (spec 2026-07-09-db-store §5): one ledger
// shape, one moment of application (connection open). Two modes ride on it —
// checked-in internal chains (migrations/*) and the app-schema push (db-store
// service), which uses the ledger's sibling `_schema` snapshot instead.
import type Database from "better-sqlite3";

export interface Migration {
  name: string;
  up: (db: Database.Database) => void;
}

// Applies the chain's pending migrations in order, each in its own transaction,
// recording each in the `_migrations` ledger. A failing migration rolls back
// atomically and throws — the caller decides whether boot degrades or dies.
export function applyMigrations(db: Database.Database, chain: Migration[]): void {
  const names = new Set(chain.map((m) => m.name));
  if (names.size !== chain.length) throw new Error("migration chain has duplicate names");
  db.exec(
    `CREATE TABLE IF NOT EXISTS _migrations (
      id         INTEGER PRIMARY KEY,
      name       TEXT NOT NULL UNIQUE,
      applied_at INTEGER NOT NULL
    )`
  );
  const done = new Set(
    (db.prepare("SELECT name FROM _migrations").all() as { name: string }[]).map((r) => r.name)
  );
  for (const m of chain) {
    if (done.has(m.name)) continue;
    const txn = db.transaction(() => {
      m.up(db);
      db.prepare("INSERT INTO _migrations (name, applied_at) VALUES (?, ?)").run(m.name, Date.now());
    });
    try {
      txn();
    } catch (e) {
      throw new Error(`migration "${m.name}" failed: ${e instanceof Error ? e.message : String(e)}`, { cause: e });
    }
  }
}
```

// The per-app db.sqlite chain (spec §5). Migration 001 is the baseline + the
// great rename: every historical shape (POC kv, tasks v0, _lodekit_-era) lands
// on the bare-_ names with data preserved. Idempotence comes from the ledger;
// the guards inside keep 001 itself safe against every starting shape.
import type Database from "better-sqlite3";
import type { Migration } from "../migrations.js";

const hasTable = (db: Database.Database, name: string): boolean =>
  db.prepare("SELECT 1 FROM sqlite_master WHERE type='table' AND name = ?").get(name) !== undefined;

const RENAMES: [string, string][] = [
  ["_lodekit_store", "_kv"],
  ["_lodekit_files", "_files"],
  ["_lodekit_setting_defs", "_setting_defs"],
  ["_lodekit_setting_values", "_setting_values"],
  ["_lodekit_task_defs", "_task_defs"],
  ["_lodekit_task_runs", "_task_runs"],
  ["_lodekit_secret_slots", "_secret_slots"],
];

export const APP_DB_CHAIN: Migration[] = [
  {
    name: "001-baseline-rename",
    up(db) {
      // tasks v0→v1 (port of the old ensureSchema's user_version check): defs
      // are manifest-reconstructed every boot, so dropping the v0 table only
      // resets schedule anchors. Runs before the rename so v0 never carries over.
      if ((db.pragma("user_version", { simple: true }) as number) < 1) {
        db.exec("DROP TABLE IF EXISTS _lodekit_task_defs");
        db.pragma("user_version = 1");
      }

      for (const [from, to] of RENAMES) {
        if (hasTable(db, from) && !hasTable(db, to)) db.exec(`ALTER TABLE ${from} RENAME TO ${to}`);
      }

      db.exec(`
        CREATE TABLE IF NOT EXISTS _kv (
          key        TEXT PRIMARY KEY,
          value      TEXT NOT NULL,
          created_at INTEGER NOT NULL,
          updated_at INTEGER NOT NULL,
          expires_at INTEGER
        );
        CREATE TABLE IF NOT EXISTS _files (
          slug         TEXT PRIMARY KEY,
          path         TEXT NOT NULL,
          title        TEXT,
          content_type TEXT NOT NULL,
          size         INTEGER NOT NULL,
          hash         TEXT NOT NULL,
          metadata     TEXT,
          created_at   INTEGER NOT NULL,
          updated_at   INTEGER NOT NULL,
          expires_at   INTEGER
        );
        CREATE TABLE IF NOT EXISTS _setting_defs (
          key           TEXT PRIMARY KEY,
          field         TEXT,
          error         TEXT,
          registered_at INTEGER NOT NULL
        );
        CREATE TABLE IF NOT EXISTS _setting_values (
          key        TEXT PRIMARY KEY,
          value      TEXT NOT NULL,
          updated_at INTEGER NOT NULL
        );
        CREATE TABLE IF NOT EXISTS _task_defs (
          name          TEXT PRIMARY KEY,
          schedule_kind TEXT,
          schedule_expr TEXT,
          catch_up_ms   INTEGER,
          retries       INTEGER,
          timeout_ms    INTEGER,
          retired       INTEGER NOT NULL DEFAULT 0,
          error         TEXT,
          registered_at INTEGER NOT NULL,
          high_water    INTEGER
        );
        CREATE TABLE IF NOT EXISTS _task_runs (
          id          INTEGER PRIMARY KEY,
          task        TEXT NOT NULL,
          state       TEXT NOT NULL,
          payload     TEXT,
          dedupe_key  TEXT,
          attempt     INTEGER NOT NULL DEFAULT 0,
          not_before  INTEGER NOT NULL,
          source      TEXT NOT NULL,
          created_at  INTEGER NOT NULL,
          started_at  INTEGER,
          finished_at INTEGER,
          duration_ms INTEGER,
          error       TEXT
        );
        CREATE TABLE IF NOT EXISTS _secret_slots (
          slot          TEXT PRIMARY KEY,
          def           TEXT,
          error         TEXT,
          registered_at INTEGER NOT NULL
        );
        CREATE TABLE IF NOT EXISTS _schema (
          id         INTEGER PRIMARY KEY CHECK (id = 1),
          snapshot   TEXT NOT NULL,
          updated_at INTEGER NOT NULL
        );
      `);

      // POC-era kv column backfill (port of kv-store's old ensureSchema): a
      // renamed (key,value) table gains the metadata columns, timestamps "now".
      const cols = new Set(
        (db.prepare("PRAGMA table_info(_kv)").all() as { name: string }[]).map((c) => c.name)
      );
      const missing = ["created_at", "updated_at", "expires_at"].filter((c) => !cols.has(c));
      for (const col of missing) db.exec(`ALTER TABLE _kv ADD COLUMN ${col} INTEGER`);
      if (missing.includes("created_at")) {
        db.prepare("UPDATE _kv SET created_at = ?, updated_at = ? WHERE created_at IS NULL")
          .run(Date.now(), Date.now());
      }

      // Indexes: drop the old names (they survive ALTER TABLE RENAME), create the _-prefixed ones.
      db.exec(`
        DROP INDEX IF EXISTS idx_store_expires;
        DROP INDEX IF EXISTS idx_files_expires;
        DROP INDEX IF EXISTS idx_task_runs_due;
        DROP INDEX IF EXISTS idx_task_runs_task;
        CREATE INDEX IF NOT EXISTS _idx_kv_expires ON _kv(expires_at) WHERE expires_at IS NOT NULL;
        CREATE INDEX IF NOT EXISTS _idx_files_expires ON _files(expires_at) WHERE expires_at IS NOT NULL;
        CREATE INDEX IF NOT EXISTS _idx_task_runs_due ON _task_runs(state, not_before);
        CREATE INDEX IF NOT EXISTS _idx_task_runs_task ON _task_runs(task, id);
      `);
    },
  },
];

Replace the body of `getAppDb` so every connection is migrated once, at open (and FKs enforce — declared app-table relations are the point of db-store):

```ts
import fs from "node:fs";
import path from "node:path";
import Database from "better-sqlite3";
import { applyMigrations } from "./migrations.js";
import { APP_DB_CHAIN } from "./migrations/appDb.js";

// Cache key is the resolved db file path, not the app id alone.
// This ensures two calls with the same app id but different dataDir
// return independent connections (app-id-only key would collide across
// different temp roots in tests).
const connections = new Map<string, { appId: string; db: Database.Database }>();

export function getAppDb(dataDir: string, appId: string): Database.Database {
  const appDataDir = path.join(dataDir, appId);
  const dbPath = path.join(appDataDir, "db.sqlite");
  const cached = connections.get(dbPath);
  if (cached) return cached.db;
  fs.mkdirSync(appDataDir, { recursive: true });
  const db = new Database(dbPath);
  db.pragma("journal_mode = WAL");
  db.pragma("foreign_keys = ON");
  applyMigrations(db, APP_DB_CHAIN);
  connections.set(dbPath, { appId, db });
  return db;
}

export function openDbs(): { appId: string; db: Database.Database }[] {
  return [...connections.values()];
}
```

```ts
import { describe, it, expect } from "vitest";
import Database from "better-sqlite3";
import { applyMigrations, type Migration } from "../src/migrations.js";
import { APP_DB_CHAIN } from "../src/migrations/appDb.js";
import { EVENTS_CHAIN, LOGS_CHAIN, SECRETS_CHAIN, SETTINGS_CHAIN } from "../src/migrations/platform.js";
import {
  APP_DB_SCHEMA, EVENTS_SCHEMA, LOGS_SCHEMA, SECRETS_SCHEMA, SETTINGS_SCHEMA,
} from "../src/internalSchema.js";

// Structural fingerprint of one database: tables (minus the applier's own
// _migrations and sqlite internals) with their columns' name/type/notnull/
// default/pk — the properties both DDL paths fully control.
function fingerprint(db: Database.Database) {
  const tables = (db
    .prepare("SELECT name FROM sqlite_master WHERE type='table' AND name != '_migrations' AND name NOT LIKE 'sqlite_%' ORDER BY name")
    .all() as { name: string }[]).map((r) => r.name);
  return Object.fromEntries(
    tables.map((t) => [
      t,
      (db.prepare(`PRAGMA table_info(${JSON.stringify(t)})`).all() as {
        name: string; type: string; notnull: number; dflt_value: unknown; pk: number;
      }[]).map(({ name, type, notnull, dflt_value, pk }) => ({
        name, type: type.toUpperCase(), notnull, dflt: dflt_value == null ? null : String(dflt_value), pk: pk > 0 ? 1 : 0,
      })),
    ])
  );
}

async function declaredDb(schema: Record<string, unknown>): Promise<Database.Database> {
  const { generateSQLiteDrizzleJson, generateSQLiteMigration } = await import("drizzle-kit/api");
  const prev = await generateSQLiteDrizzleJson({});
  const cur = await generateSQLiteDrizzleJson(schema as Record<string, never>);
  const statements = await generateSQLiteMigration(prev, cur);
  const db = new Database(":memory:");
  for (const s of statements) db.exec(s);
  return db;
}

describe("internal declarations match the migration chains", () => {
  it.each([
    ["app-db", APP_DB_CHAIN, APP_DB_SCHEMA],
    ["events", EVENTS_CHAIN, EVENTS_SCHEMA],
    ["logs", LOGS_CHAIN, LOGS_SCHEMA],
    ["secrets", SECRETS_CHAIN, SECRETS_SCHEMA],
    ["settings", SETTINGS_CHAIN, SETTINGS_SCHEMA],
  ] as const)("%s", async (_name, chain, schema) => {
    const migrated = new Database(":memory:");
    applyMigrations(migrated, chain as Migration[]);
    expect(fingerprint(migrated)).toEqual(fingerprint(await declaredDb(schema)));
  });
});
```

// The db-store service (spec 2026-07-09-db-store): the app's relational
// database. This module is the data plane (query/batch/select/schema); the
// schema push (applySchemaPush) lands beside it. Statement-text guards are
// deliberately "organized, not paranoid" (spec §2): apps are user-trusted
// local code; better-sqlite3 has no authorizer.
import fs from "node:fs";
import path from "node:path";
import type Database from "better-sqlite3";
import BetterSqlite3 from "better-sqlite3";
import { Hono, type MiddlewareHandler } from "hono";
import { zValidator } from "@hono/zod-validator";
import { z } from "zod";
import { getAppDb } from "../db.js";
import type { Config } from "../config.js";
import { isValidAppId } from "../registry.js";
import { emitEvent, PLATFORM_NS, CHANGE_FEED_TTL_S } from "../events.js";
import { validationHook } from "../validation.js";

export const CATALOG_NAME = "db-store";

/** Validation/semantic error — mapped to HTTP 400 by the router. */
export class DbError extends Error {
  constructor(message?: string) {
    super(message);
    this.name = "DbError";
  }
}

// ---------- statement guards ----------

const ALLOWED_FIRST = /^\s*(select|insert|update|delete|replace|with)\b/i;
// Internal/system table reference after a structural keyword. String literals
// containing "_foo" don't match (no keyword before them) — good enough at the
// local-trust posture; sqlite_master et al are also caught here.
const INTERNAL_REF = /\b(?:from|into|update|join|table)\s+["'`[]?(?:_|sqlite_)/i;

export function assertAllowed(sql: string): void {
  if (!ALLOWED_FIRST.test(sql)) throw new DbError("only SELECT/INSERT/UPDATE/DELETE/REPLACE/WITH statements are allowed — schema changes come from src/db.ts");
  if (INTERNAL_REF.test(sql)) throw new DbError("statements may not reference _-prefixed or sqlite_ tables");
}

// ---------- query execution (the sqlite-proxy contract) ----------

export type ProxyMethod = "run" | "all" | "get" | "values";
export interface ProxyQuery { sql: string; params: (string | number | null)[]; method: ProxyMethod }

// Rows are RAW ARRAYS (drizzle's sqlite-proxy wire shape): all/values ->
// unknown[][]; get -> flat unknown[] (empty when missing); run -> [].
export function runQuery(db: Database.Database, q: ProxyQuery): { rows: unknown[] } {
  assertAllowed(q.sql);
  const stmt = db.prepare(q.sql); // single statement only — prepare throws on trailing SQL
  if (q.method === "run" && !stmt.reader) {
    stmt.run(...q.params);
    return { rows: [] };
  }
  if (q.method === "get") {
    const row = stmt.raw().get(...q.params) as unknown[] | undefined;
    return { rows: row ?? [] };
  }
  return { rows: stmt.raw().all(...q.params) as unknown[] };
}

// ---------- change feed ----------

const EVENT = `${CATALOG_NAME}-change`;
const WRITE_OP = /^\s*(insert|update|delete|replace)\b/i;
// drizzle emits regular SQL — the target table is extractable for the common
// shapes; misses (e.g. WITH-prefixed writes) just omit `table`.
const TABLE_OF = /\b(?:into|update|from)\s+["'`[]?([a-z0-9_$]+)/i;

function emitChange(appId: string, sql: string): void {
  const op = WRITE_OP.exec(sql)?.[1]?.toLowerCase();
  if (!op) return;
  const table = TABLE_OF.exec(sql)?.[1];
  emitEvent({
    ns: appId, source: PLATFORM_NS, type: EVENT,
    payload: table ? { op, table } : { op },
    ttl: CHANGE_FEED_TTL_S,
  });
}

// ---------- introspection ----------

export function userSchema(db: Database.Database): { tables: { name: string; columns: unknown[]; indexes: string[] }[] } {
  const tables = (db
    .prepare("SELECT name FROM sqlite_master WHERE type='table' AND name NOT LIKE '\\_%' ESCAPE '\\' AND name NOT LIKE 'sqlite\\_%' ESCAPE '\\' ORDER BY name")
    .all() as { name: string }[]).map((r) => r.name);
  return {
    tables: tables.map((name) => ({
      name,
      columns: (db.prepare(`PRAGMA table_info(${JSON.stringify(name)})`).all() as {
        name: string; type: string; notnull: number; dflt_value: unknown; pk: number;
      }[]).map((c) => ({ name: c.name, type: c.type, notNull: c.notnull === 1, default: c.dflt_value ?? null, pk: c.pk > 0 })),
      indexes: (db.prepare(`PRAGMA index_list(${JSON.stringify(name)})`).all() as { name: string }[])
        .map((i) => i.name).filter((n) => !n.startsWith("sqlite_")),
    })),
  };
}

// ---------- middleware + routes ----------

export type DbEnv = { Variables: { db: Database.Database; appId: string; dbPath: string } };

export function withDbStore(cfg: Config): MiddlewareHandler<DbEnv> {
  return async (c, next) => {
    const appId = c.req.param("appId");
    if (!appId || !isValidAppId(appId)) return c.json({ error: "invalid app id" }, 400);
    c.set("appId", appId);
    c.set("dbPath", path.join(cfg.dataDir, appId, "db.sqlite"));
    // GET /schema and /select must not materialize a data dir for an app that
    // never stored anything — they open lazily; /query and /batch do create.
    await next();
  };
}

const paramsSchema = z.array(z.union([z.string(), z.number(), z.null()]));
const querySchema = z.object({
  sql: z.string().min(1).max(100_000),
  params: paramsSchema,
  method: z.enum(["run", "all", "get", "values"]),
});
const batchSchema = z.object({ queries: z.array(querySchema).min(1).max(100) });
const selectSchema = z.object({ sql: z.string().min(1).max(100_000), params: paramsSchema.optional() });

export const dbRoutes = new Hono<DbEnv>()
  .onError((err, c) => c.json({ error: err instanceof Error ? err.message : String(err) }, 400))
  .get("/schema", (c) => {
    if (!fs.existsSync(c.var.dbPath)) return c.json({ tables: [] });
    return c.json(userSchema(getAppDb(path.dirname(path.dirname(c.var.dbPath)), c.var.appId)));
  })
  .post("/query", zValidator("json", querySchema, validationHook), (c) => {
    const q = c.req.valid("json");
    const db = getAppDb(path.dirname(path.dirname(c.var.dbPath)), c.var.appId);
    const result = runQuery(db, q);
    emitChange(c.var.appId, q.sql);
    return c.json(result);
  })
  .post("/batch", zValidator("json", batchSchema, validationHook), (c) => {
    const { queries } = c.req.valid("json");
    const db = getAppDb(path.dirname(path.dirname(c.var.dbPath)), c.var.appId);
    const txn = db.transaction(() => queries.map((q) => runQuery(db, q)));
    const results = txn();
    for (const q of queries) emitChange(c.var.appId, q.sql);
    return c.json({ results });
  })
  // SELECT-only, on a short-lived READ-ONLY connection: the guarantee is the
  // connection's, not a SQL parse's (spec §8/§9). Rows come back as objects —
  // this door serves agents and the future data explorer, not the proxy driver.
  .post("/select", zValidator("json", selectSchema, validationHook), (c) => {
    const { sql, params } = c.req.valid("json");
    assertAllowed(sql);
    if (!fs.existsSync(c.var.dbPath)) return c.json({ error: "no database for this app yet" }, 404);
    const ro = new BetterSqlite3(c.var.dbPath, { readonly: true, fileMustExist: true });
    try {
      const stmt = ro.prepare(sql);
      if (!stmt.reader) throw new DbError("only SELECT statements are allowed here");
      return c.json({ rows: stmt.all(...(params ?? [])) });
    } finally {
      ro.close();
    }
  });

export type DbRoutes = typeof dbRoutes;

```ts
// ---------- schema push (spec §7): declared schema -> live database ----------

export type PushResult =
  | { status: "applied"; statements: number }
  | { status: "gated"; message: string }
  | { status: "noop" };

const ADDITIVE = [/^create table\b/i, /^create (unique )?index\b/i, /^alter table .* add( column)?\b/i];
const isAdditive = (s: string) => ADDITIVE.some((re) => re.test(s.trim()));

const EXPAND_COPY =
  "Destructive schema changes don't auto-apply. Iterate additively (expand-copy): add the new column/table, " +
  "copy data across in app code, switch reads, stop writing the old one. (Accepting destructive migrations is on the roadmap.)";

function emitSchemaState(appId: string, payload: Record<string, unknown>): void {
  emitEvent({ ns: appId, source: PLATFORM_NS, type: "schema-state", payload, ttl: CHANGE_FEED_TTL_S });
}

// The db-manifest hook's handler (wired in server.ts). Contract mirrors the
// settings manifest: a load error keeps the previous schema; internal
// namespaces are skipped; an app that declares nothing never materializes a
// database. Returns the outcome for tests/observability; callers may ignore it.
export async function applySchemaPush(
  dataDir: string,
  appId: string,
  snapshot: unknown,
  loadError?: string
): Promise<PushResult> {
  if (!isValidAppId(appId)) return { status: "noop" }; // _dashboard et al
  if (loadError) {
    const message = `src/db.ts failed to load — keeping the previous schema`;
    emitLog("error", "db-store", message, { stack: loadError }, appId);
    emitSchemaState(appId, { status: "gated", message });
    return { status: "gated", message };
  }
  const tables =
    snapshot && typeof snapshot === "object" && "tables" in snapshot
      ? Object.keys((snapshot as { tables: Record<string, unknown> }).tables ?? {})
      : null;
  if (tables === null) {
    const message = "src/db.ts produced no schema snapshot — keeping the previous schema";
    emitLog("error", "db-store", message, undefined, appId);
    return { status: "gated", message };
  }
  // Never materialize a data dir for an app that declares no tables and has none.
  if (tables.length === 0 && !fs.existsSync(path.join(dataDir, appId, "db.sqlite"))) return { status: "noop" };

  const bad = tables.filter((t) => t.startsWith("_") || t.startsWith("sqlite_"));
  if (bad.length > 0) {
    const message = `table names may not start with "_" or "sqlite_": ${bad.join(", ")}`;
    emitLog("error", "db-store", message, undefined, appId);
    emitSchemaState(appId, { status: "gated", message });
    return { status: "gated", message };
  }

  const { generateSQLiteDrizzleJson, generateSQLiteMigration } = await import("drizzle-kit/api");
  const db = getAppDb(dataDir, appId);
  const prevRow = db.prepare("SELECT snapshot FROM _schema WHERE id = 1").get() as { snapshot: string } | undefined;
  const prev = prevRow ? JSON.parse(prevRow.snapshot) : await generateSQLiteDrizzleJson({});
  let statements: string[];
  try {
    statements = await generateSQLiteMigration(prev, snapshot as Parameters<typeof generateSQLiteMigration>[1]);
  } catch (e) {
    const message = `schema diff failed: ${e instanceof Error ? e.message : String(e)}`;
    emitLog("error", "db-store", message, undefined, appId);
    emitSchemaState(appId, { status: "gated", message });
    return { status: "gated", message };
  }
  if (statements.length === 0) return { status: "noop" };

  const destructive = statements.filter((s) => !isAdditive(s));
  if (destructive.length > 0) {
    const message = `schema change gated — would require:\n${destructive.join(";\n")}\n${EXPAND_COPY}`;
    emitLog("error", "db-store", message, undefined, appId);
    emitSchemaState(appId, { status: "gated", message });
    return { status: "gated", message };
  }

  try {
    const txn = db.transaction(() => {
      for (const s of statements) db.exec(s);
      db.prepare(
        `INSERT INTO _schema (id, snapshot, updated_at) VALUES (1, @snap, @now)
         ON CONFLICT(id) DO UPDATE SET snapshot = excluded.snapshot, updated_at = excluded.updated_at`
      ).run({ snap: JSON.stringify(snapshot), now: Date.now() });
    });
    txn();
  } catch (e) {
    // A statement the diff produced but the database refused (e.g. a table that
    // pre-exists outside snapshot lineage) — same surface as the gate (spec §7).
    const message = `schema apply failed: ${e instanceof Error ? e.message : String(e)}`;
    emitLog("error", "db-store", message, undefined, appId);
    emitSchemaState(appId, { status: "gated", message });
    return { status: "gated", message };
  }
  emitLog("info", "db-store", `schema applied (${statements.length} statement${statements.length === 1 ? "" : "s"})`, undefined, appId);
  emitSchemaState(appId, { status: "applied", statements: statements.length });
  return { status: "applied", statements: statements.length };
}
```

// The db handle's factory (spec §6/§8): a drizzle instance on the sqlite-proxy
// driver whose "driver" is HTTP against the scoped API — full typed query
// building client-side, execution host-side, workers never touch sqlite.
import { drizzle, type SqliteRemoteDatabase } from "drizzle-orm/sqlite-proxy";

async function post<T>(url: string, body: unknown): Promise<T> {
  const res = await fetch(url, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify(body),
  });
  if (!res.ok) {
    let message = res.statusText;
    try {
      const data = (await res.json()) as { error?: string };
      if (data?.error) message = data.error;
    } catch {
      // non-JSON error body — keep statusText
    }
    throw new Error(message);
  }
  return (await res.json()) as T;

export function createRemoteDb<TSchema extends Record<string, unknown>>(opts: {
  baseUrl: string;
  appId: string;
  schema: TSchema;
}): SqliteRemoteDatabase<TSchema> {
  const api = `${opts.baseUrl}/api/apps/${opts.appId}/db-store`;
  return drizzle<TSchema>(
    async (sql, params, method) => post(`${api}/query`, { sql, params, method }),
    async (queries) => {
      const { results } = await post<{ results: { rows: unknown[] }[] }>(`${api}/batch`, { queries });
      return results;
    },
    { schema: opts.schema }
  );
}

export const CARE_VERB: Record<CareKind, string> = { water: "Watered", feed: "Fed", mist: "Misted" };

export type CareEvery = Partial<Record<CareKind, string>>;
/** kind -> due info, assembled from care_state rows. */
export type DueByKind = Partial<Record<CareKind, { dueAt: number }>>;

export const careByKind = (rules: { kind: string; every: string }[]): CareEvery =>
  Object.fromEntries(rules.map((r) => [r.kind as CareKind, r.every]));
export const dueByKind = (states: { kind: string; dueAt: number }[]): DueByKind =>
  Object.fromEntries(states.map((s) => [s.kind as CareKind, { dueAt: s.dueAt }]));

export const snoozeKey = (id: number) => `snooze:${id}`;

/** Inverted zero-padded epoch ms — newer stamps sort FIRST under file-store's
 *  ascending prefix listing, so photo timelines read newest-first. */
export const invTs = (ms: number) => String(99_999_999_999_999 - ms).padStart(14, "0");

/** "3d" / "12h" → milliseconds. Throws on anything else. */
export function parseEvery(every: string): number {
  const m = /^(\d+)([dh])$/.exec(every.trim());
  if (!m) throw new Error(`invalid interval "${every}" — use e.g. "3d" or "12h"`);
  return Number(m[1]) * (m[2] === "d" ? 86_400_000 : 3_600_000);
}

export type MoodKey = "thriving" | "content" | "parched" | "hungry" | "dusty" | "wilting";
export interface Mood {
  key: MoodKey;
  emoji: string;
  label: string;
}

/**
 * Deterministic mood from care state: the worst-overdue kind wins.
 * over > 1 interval past due → wilting; past due → parched/hungry/dusty by kind;
 * otherwise a 7+ streak is thriving, else content.
 */
export function moodFor(care: CareEvery, due: DueByKind, streak: number, now: number): Mood {
  let worst = 0;
  let worstKind: CareKind = "water";
  for (const kind of CARE_KINDS) {
    const every = care[kind];
    const d = due[kind];
    if (!every || !d) continue;
    const over = (now - d.dueAt) / parseEvery(every);
    if (over > worst) {
      worst = over;
      worstKind = kind;
    }
  }
  if (worst > 1) return { key: "wilting", emoji: "🥀", label: "wilting — needs attention" };
  if (worst > 0) {
    if (worstKind === "water") return { key: "parched", emoji: "🏜️", label: "parched" };
    if (worstKind === "feed") return { key: "hungry", emoji: "😋", label: "hungry" };
    return { key: "dusty", emoji: "🌫️", label: "missing a misting" };
  }
  if (streak >= 7) return { key: "thriving", emoji: "🌟", label: `thriving — ${streak}-care streak` };
  return { key: "content", emoji: "🙂", label: "content" };
}

/** Idempotent first-open seed. Returns true when it seeded. */
export async function seedIfNeeded(): Promise<boolean> {
  if (await kv.has("seeded")) return false;
  const now = Date.now();
  for (const seed of SEEDS) {
    const adoptedAt = now - seed.daysAgo * 86_400_000;
    const [{ id }] = await db
      .insert(plants)
      .values({ ...seed.plant, adoptedAt })
      .returning({ id: plants.id });
    await files.put(portraitSvg(seed.plant.icon, id), {
      slug: `cover-${id}`, contentType: "image/svg+xml", title: `${seed.plant.name}'s portrait`,
    });
    await files.put(portraitSvg(seed.plant.icon, id + 1), {
      slug: `photo-${id}-${invTs(adoptedAt)}`, contentType: "image/svg+xml",
      title: "Adoption day", metadata: { plantId: id },
    });
    const stateRows: (typeof careState.$inferInsert)[] = [];
    const journalRows: (typeof journal.$inferInsert)[] = [];
    let i = 0;
    for (const [kind, every] of Object.entries(seed.every) as [CareKind, string][]) {
      const ms = parseEvery(every);
      // Stagger due times per the seed's story (same arithmetic as before).
      const dueAt =
        seed.story === "overdue" ? now - Math.floor(ms / 2)
        : seed.story === "dueSoon" ? now + Math.floor(Math.min(ms, 86_400_000) / 4)
        : now + ms;
      const lastAt = dueAt - ms;
      const stampAt = lastAt - i * 60_000;
      i++;
      const reminderRunId = await tasks.enqueue("care-reminder", { plantId: id, kind }, { at: dueAt, dedupeKey: `${id}:${kind}` });
      stateRows.push({ plantId: id, kind, lastAt, dueAt, reminderRunId });
      journalRows.push({ plantId: id, at: stampAt, kind, text: `${CARE_VERB[kind]} ${seed.plant.name}.` });
    }
    journalRows.push({ plantId: id, at: adoptedAt, text: `${seed.plant.name} joined the conservatory.` });
    // One transaction for the plant's dependents — db.batch is the transaction story.
    await db.batch([
      db.insert(careRules).values(
        (Object.entries(seed.every) as [CareKind, string][]).map(([kind, every]) => ({ plantId: id, kind, every }))
      ),
      db.insert(careState).values(stateRows),
      db.insert(journal).values(journalRows),
    ]);
    await kv.set(streakKey(id), seed.streak);
    if (seed.story === "snoozed") await kv.set(snoozeKey(id), true, { ttl: 86_400 });
  }
  await kv.set("seeded", { at: now, version: 2 });
  logs.info("conservatory seeded", { plants: SEEDS.length });
  return true;
}

````markdown
## Choosing storage: Database (`db`) vs KV (`kv`)

Two per-app stores; choose by data kind, without asking the person (they can steer):

- **Database (db-store) — the default for domain records.** Anything that is an
  *entity*: it has fields, has relationships, gets listed/filtered/aggregated, would
  hurt to lose. Recipes, expenses, plants, rows saved from an integration.
- **KV (kv-store) — app memory.** Counters, cursors, preferences, caches, last-seen
  offsets, flags: small values the app writes about itself.

If you're modeling it with composite keys (`checkin:<id>:<day>`) or scanning prefixes
to "join", it's an entity — put it in the database.

## Database (db-store)

Declare the schema in `src/db.ts` — drizzle tables plus the app's typed client:

```ts
import { sqliteTable, text, integer } from "drizzle-orm/sqlite-core";
import { createDb } from "@lodekit/sdk";

export const recipes = sqliteTable("recipes", {
  id: integer("id").primaryKey({ autoIncrement: true }),
  title: text("title").notNull(),
  addedAt: integer("added_at", { mode: "timestamp" }).notNull(),
});

export const db = createDb({ recipes });
```

- **Schema applies on save.** The runtime diffs your declaration against the live
  database at boot: additive changes (new table/column/index) apply automatically —
  never write migrations, never run a CLI.
- **No breaking changes.** Destructive changes (drop/rename/type change) are *gated*:
  they don't apply, and the app reports a `schema-state` error explaining what would
  be lost. Iterate additively (expand-copy): add the new column or table, copy data in
  app code, switch reads, stop writing the old one.
- Table and column names are snake_case, written explicitly (as above). Table names
  must not start with `_` (reserved for the platform).
- **Query anywhere** with the full drizzle builder — server functions, loaders, and
  the browser all work: `await db.select().from(recipes).where(eq(recipes.id, id))`,
  joins, `groupBy`/`count`, `insert().returning()`, `onConflictDoUpdate`.
  Import operators from `drizzle-orm` (`eq`, `and`, `desc`, `count`, `sql`, …).
- **Transactions are `db.batch([...])`** (the proxy driver has no interactive
  transactions). Complex reads can drop to the escape hatch:
  `` await db.all(sql`SELECT …`) ``.
- Declare relations with `.references(() => other.id, { onDelete: "cascade" })` —
  foreign keys are enforced; cascades replace manual cleanup loops.
- Blobs don't transport over the query door — binary belongs in Files.
- Validate user input with derived schemas where useful: `drizzle-zod`'s
  `createInsertSchema(recipes)` — derived from the table, never a second source of truth.
- Live refresh: `events.watch({ type: "db-store-change" }, () => …invalidate…)` —
  same pattern as the kv feed; payloads carry identity (`{ op, table }`), never values.
- **Via MCP**: `lodekit_db_schema` (the declared tables) and `lodekit_db_query`
  (SELECT-only) — inspect real data before assuming a change worked.
````
