# Gateways v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The gateways service per `docs/specs/2026-07-10-gateways-design.md`: agent-authored declarative gateway manifests in a `gateways/` root tree, per-app connections (secret slots linked, config slots set), and a host-side chokepoint that injects credentials (static + OAuth 2.0), enforces rate limits / circuit breaking / timeouts / size caps, and records every request in the log-store — credentials never enter the app worker.

**Architecture:** Manifests load from `<root>/gateways/<provider-id>/manifest.json` into an in-memory registry (watched, degrade-not-die). Connections persist in `data/_platform/gateways.sqlite` (`links` mirrors the secrets links shape one level deeper; `config_values` plain; `oauth_tokens` AES-256-GCM via the secret-store key-provider rail). Apps declare aliases in `src/gateways.ts` (the settings/secrets worker-boot-manifest mechanism verbatim). The only traffic door is `POST /api/apps/:appId/gateways/:alias/request`, worker-token gated; the engine assembles the URL host-side (egress by construction), injects auth, applies guards, buffers under a cap, and emits one log record per request plus `gateway-change`/`gateway-health` events.

**Tech Stack:** Node/Hono/tsx (buildless runtime), better-sqlite3, zod + `@hono/zod-validator`, Node `crypto` (PKCE, AES-256-GCM — zero new dependencies), vitest, TanStack Start dashboard with `@lodekit/ui`.

## Global Constraints

- Catalog name **`gateways`**, SDK handle **`gateways`** (context.md mapping). Events: **`gateway-change`** (change feed) and **`gateway-health`** (breaker + connection health). Log source: **`gateway:<provider-id>`**.
- Terminology (spec §3): **gateway** (the door, person-facing), **provider** (the external party), **connection** (app×gateway, keyed `(appId, alias)`), **linked/set/pending** slots. "Integration" never names a stored object, route, or table. "Instance" and "fill" are retired words.
- Provider id grammar: `/^[a-z0-9-]+$/`, max 64 (the app-id grammar). Alias + slot grammar: `/^[a-z0-9_]+$/`, max 64 (the settings-key grammar).
- Routes: platform `/api/gateways` (+ `/oauth/callback`, `/:providerId`, `/:providerId/favicon`), per-app `/api/apps/:appId/gateways`. The ONLY traffic route is `POST /api/apps/:appId/gateways/:alias/request` — worker token header **`x-lodekit-worker-token`** required, checked FIRST (no oracle).
- Egress by construction: app code never supplies an absolute URL; descriptor `path` must start `/`; the resolved URL must stay under the manifest `base_url` (origin + path prefix). `http:` base URLs only for localhost/RFC-1918 hosts.
- Credentials never appear in any route response, log record, event payload, or the dashboard. Injected values double as the redaction map (`•••`). `Authorization`/`Cookie`/`Set-Cookie` never land in captured data; `Set-Cookie` is stripped from response envelopes.
- Typed failure reasons (engine + SDK): `unconfigured`, `rate_limited`, `breaker_open`, `needs_reauth`, `timeout`, `too_large`, `network`, `unavailable`. HTTP mapping: 409, 429, 503, 409, 504, 502, 502, 503 respectively — the body always carries `{ error, reason }`.
- Guardrails: token bucket + concurrency cap + breaker are **per provider**; 4xx never trips the breaker; 401/403 mark the **connection** unhealthy; provider 429 `Retry-After` pauses the bucket (cap 15 min). NO request-level retries (Tasks owns retries).
- Settings section **"Gateways"** (all global scope): `gateways.default_timeout` (duration "10s"), `gateways.default_rate` (string "60/min"), `gateways.default_concurrency` (4), `gateways.max_response_bytes` (10_000_000), `gateways.capture_bodies` (false), `gateways.breaker_failure_threshold` (5, advanced), `gateways.breaker_cooldown` (duration "30s", advanced). (The spec's `_ms` names land as duration fields — the settings grammar's idiom; the docs-closure task aligns spec §11.)
- Hard caps stay code: request timeout ceiling 60 s; OAuth pending-state TTL 10 min; config value max 4096 bytes; capture-bodies truncation 2048 chars/side.
- OAuth 2.0: authorization-code + PKCE (S256 via `node:crypto`), plain `fetch` token exchange/refresh — zero new packages. Tokens encrypted at rest with the secret-store master key; write-only; a failed refresh flips the connection to needs-reauth.
- Commit style: match repo (`feat(runtime): …`). **No `Co-Authored-By` trailers** (CLAUDE.md). Surgical changes; match neighboring file style.
- All work on the current `service` branch; never fold to master unattended.

```ts
// Gateway manifests (spec 2026-07-10-gateways §4): the gateways tree
// (<root>/gateways/<provider-id>/manifest.json + favicon) loaded into an
// in-memory registry. The tree on disk is the source of truth — nothing
// manifest-shaped is copied into SQLite. An invalid manifest degrades, never
// dies: the entry carries its error; calls against it fail typed.
import fs from "node:fs";
import path from "node:path";
import { z } from "zod";
import type { Config } from "./config.js";

export const PROVIDER_ID_RE = /^[a-z0-9-]+$/;
const SLOT_RE = /^[a-z0-9_]+$/;
const RATE_RE = /^\d+\/(second|sec|s|minute|min|m|hour|hr|h)$/;
const SLOT_NAME = z.string().regex(SLOT_RE).max(64);
const FAVICON_NAMES = ["favicon.svg", "favicon.png", "favicon.ico"];

// http:// is allowed only toward the person's own network (a local Home
// Assistant) — loopback, RFC-1918, and mDNS .local names. Public hosts get https.
export function isPrivateHost(hostname: string): boolean {
  const h = hostname.toLowerCase().replace(/^\[|\]$/g, "");
  if (h === "localhost" || h.endsWith(".localhost") || h === "::1" || h.endsWith(".local")) return true;
  const m = h.match(/^(\d+)\.(\d+)\.\d+\.\d+$/);
  if (!m) return false;
  const [a, b] = [Number(m[1]), Number(m[2])];
  return a === 127 || a === 10 || (a === 192 && b === 168) || (a === 172 && b >= 16 && b <= 31);
}

const slotDef = z.object({
  kind: z.enum(["secret", "config"]),
  label: z.string().min(1).max(200),
  description: z.string().max(500).optional(),
  optional: z.boolean().optional(),
});

const auth = z.discriminatedUnion("kind", [
  z.object({ kind: z.literal("none") }),
  z.object({
    kind: z.literal("api_key"),
    in: z.enum(["query", "header"]),
    param: z.string().min(1).max(100).optional(),
    header: z.string().min(1).max(100).optional(),
    slot: SLOT_NAME,
  }),
  z.object({ kind: z.literal("bearer"), slot: SLOT_NAME }),
  z.object({ kind: z.literal("basic"), username_slot: SLOT_NAME, password_slot: SLOT_NAME }),
  z.object({
    kind: z.literal("oauth2"),
    authorization_url: z.string().url(),
    token_url: z.string().url(),
    scopes: z.array(z.string().min(1).max(100)).max(20).optional(),
    pkce: z.boolean().optional(), // default true, applied at use
    client_id_slot: SLOT_NAME,
    client_secret_slot: SLOT_NAME.optional(),
  }),
]);

export const manifestSchema = z
  .object({
    name: z.string().min(1).max(100),
    website: z.string().url().optional(),
    base_url: z.union([z.string().url(), z.object({ from_slot: SLOT_NAME })]),
    auth,
    slots: z.record(SLOT_NAME, slotDef).default({}),
    limits: z
      .object({
        rate: z.string().regex(RATE_RE).optional(),
        concurrency: z.number().int().min(1).max(32).optional(),
        timeout_ms: z.number().int().min(100).max(60_000).optional(),
      })
      .optional(),
  })
  .superRefine((m, ctx) => {
    const issue = (message: string) => ctx.addIssue({ code: z.ZodIssueCode.custom, message });
    // Every slot the auth recipe (or base_url) references must be declared with
    // the right kind: credentials are secret slots; client ids / base URLs are config.
    const needs: [string, "secret" | "config"][] = [];
    const a = m.auth;
    if (a.kind === "api_key") {
      if (a.in === "query" && !a.param) issue('api_key in "query" needs "param"');
      if (a.in === "header" && !a.header) issue('api_key in "header" needs "header"');
      needs.push([a.slot, "secret"]);
    }
    if (a.kind === "bearer") needs.push([a.slot, "secret"]);
    if (a.kind === "basic") needs.push([a.username_slot, "secret"], [a.password_slot, "secret"]);
    if (a.kind === "oauth2") {
      needs.push([a.client_id_slot, "config"]);
      if (a.client_secret_slot) needs.push([a.client_secret_slot, "secret"]);
    }
    if (typeof m.base_url === "string") {
      const u = new URL(m.base_url);
      if (u.protocol !== "http:" && u.protocol !== "https:") issue("base_url must be http(s)");
      else if (u.protocol === "http:" && !isPrivateHost(u.hostname)) {
        issue("http base_url is allowed only for localhost/private hosts");
      }
    } else {
      needs.push([m.base_url.from_slot, "config"]);
    }
    for (const [slot, kind] of needs) {
      const def = m.slots[slot];
      if (!def) issue(`referenced slot "${slot}" is not declared`);
      else if (def.kind !== kind) issue(`slot "${slot}" must be kind "${kind}"`);
    }
  });

export type GatewayManifest = z.infer<typeof manifestSchema>;

export interface GatewayEntry {
  providerId: string;
  manifest: GatewayManifest | null;
  error: string | null;
  dir: string;
  faviconFile: string | null;
}

let registry = new Map<string, GatewayEntry>();
let cfgRef: Config | null = null;

function loadEntry(gatewaysDir: string, providerId: string): GatewayEntry {
  const dir = path.join(gatewaysDir, providerId);
  const faviconFile = FAVICON_NAMES.map((f) => path.join(dir, f)).find((f) => fs.existsSync(f)) ?? null;
  const file = path.join(dir, "manifest.json");
  try {
    const raw: unknown = JSON.parse(fs.readFileSync(file, "utf8"));
    const parsed = manifestSchema.safeParse(raw);
    if (!parsed.success) {
      const msg = parsed.error.issues.map((i) => (i.path.length ? `${i.path.join(".")}: ${i.message}` : i.message)).join("; ");
      return { providerId, manifest: null, error: msg, dir, faviconFile };
    }
    return { providerId, manifest: parsed.data, error: null, dir, faviconFile };
  } catch (e) {
    return { providerId, manifest: null, error: e instanceof Error ? e.message : String(e), dir, faviconFile };
  }
}

function scan(gatewaysDir: string): Map<string, GatewayEntry> {
  const next = new Map<string, GatewayEntry>();
  let entries: fs.Dirent[] = [];
  try {
    entries = fs.readdirSync(gatewaysDir, { withFileTypes: true });
  } catch {
    return next; // no gateways tree yet — an empty registry, not an error
  }
  for (const e of entries) {
    if (!e.isDirectory()) continue;
    if (!PROVIDER_ID_RE.test(e.name) || e.name.length > 64) continue; // .DS_Store-class noise
    next.set(e.name, loadEntry(gatewaysDir, e.name));
  }
  return next;
}

export function initGatewayManifests(cfg: Config): void {
  cfgRef = cfg;
  registry = scan(cfg.gatewaysDir);
}

/** Rescan the tree; returns the provider ids whose entry changed, appeared, or vanished. */
export function reloadGatewayManifests(): string[] {
  if (!cfgRef) return [];
  const next = scan(cfgRef.gatewaysDir);
  const changed: string[] = [];
  for (const id of new Set([...registry.keys(), ...next.keys()])) {
    const a = registry.get(id), b = next.get(id);
    if (!a || !b || JSON.stringify(a) !== JSON.stringify(b)) changed.push(id);
  }
  registry = next;
  return changed.sort();
}

export function listGatewayEntries(): GatewayEntry[] {
  return [...registry.values()].sort((a, b) => a.providerId.localeCompare(b.providerId));
}

export function getGatewayEntry(providerId: string): GatewayEntry | undefined {
  return registry.get(providerId);
}

export function resetGatewayManifestsForTest(): void {
  registry = new Map();
  cfgRef = null;
}
```

```ts
import { describe, it, expect } from "vitest";
import { parseRate, TokenBucket, Breaker, Semaphore } from "../src/gatewayGuards.js";

describe("parseRate", () => {
  it("parses the grammar and rejects junk", () => {
    expect(parseRate("60/min")).toEqual({ capacity: 60, windowMs: 60_000 });
    expect(parseRate("2/second")).toEqual({ capacity: 2, windowMs: 1_000 });
    expect(parseRate("100/hour")).toEqual({ capacity: 100, windowMs: 3_600_000 });
    expect(() => parseRate("fast")).toThrow();
    expect(() => parseRate("0/min")).toThrow();
  });
});

describe("TokenBucket", () => {
  it("grants up to capacity, then refills continuously", () => {
    const b = new TokenBucket(2, 1_000);
    const t0 = 1_000_000;
    expect(b.tryTake(t0)).toBe(true);
    expect(b.tryTake(t0)).toBe(true);
    expect(b.tryTake(t0)).toBe(false);
    expect(b.msUntilNext(t0)).toBeGreaterThan(0);
    expect(b.tryTake(t0 + 600)).toBe(true); // 0.6s @ 2/s refilled >= 1 token
  });

  it("pauseUntil (Retry-After) blocks takes until the pause lifts", () => {
    const b = new TokenBucket(10, 1_000);
    const t0 = 2_000_000;
    b.pauseUntil(t0 + 500);
    expect(b.tryTake(t0)).toBe(false);
    expect(b.msUntilNext(t0)).toBeGreaterThanOrEqual(500);
    expect(b.tryTake(t0 + 501)).toBe(true);
  });

  it("acquire waits within its budget and gives up beyond it", async () => {
    const b = new TokenBucket(1, 200);
    expect(await b.acquire(10)).toBe(true);       // token available immediately
    expect(await b.acquire(500)).toBe(true);      // refills within the wait budget
    expect(await b.acquire(5)).toBe(false);       // 5ms can't cover a 200ms window
  });
});

describe("Breaker", () => {
  it("opens at the threshold, half-opens after cooldown, closes on a probe success", () => {
    const br = new Breaker(3, 1_000);
    const t0 = 3_000_000;
    expect(br.tryPass(t0)).toBe(true);
    expect(br.recordFailure(t0)).toBeNull();
    expect(br.recordFailure(t0)).toBeNull();
    expect(br.recordFailure(t0)).toBe("opened");
    expect(br.state).toBe("open");
    expect(br.tryPass(t0 + 500)).toBe(false);
    expect(br.tryPass(t0 + 1_001)).toBe(true);   // half-open: one probe passes
    expect(br.state).toBe("half-open");
    expect(br.tryPass(t0 + 1_002)).toBe(false);  // probe slot is taken
    expect(br.recordSuccess()).toBe("closed");
    expect(br.state).toBe("closed");
    expect(br.tryPass(t0 + 1_003)).toBe(true);
  });

  it("a failed half-open probe reopens; successes reset the failure count", () => {
    const br = new Breaker(2, 1_000);
    const t0 = 4_000_000;
    br.recordFailure(t0);
    expect(br.recordSuccess()).toBeNull(); // closed stays closed — no transition
```

```ts
// Pure guardrail primitives for the gateways engine (spec 2026-07-10-gateways §9).
// All per-provider state (buckets, breakers, semaphores) is in-memory only —
// a restart forgives (spec §8).

const UNITS: Record<string, number> = {
  second: 1_000, sec: 1_000, s: 1_000,
  minute: 60_000, min: 60_000, m: 60_000,
  hour: 3_600_000, hr: 3_600_000, h: 3_600_000,
};

export function parseRate(rate: string): { capacity: number; windowMs: number } {
  const m = /^(\d+)\/(second|sec|s|minute|min|m|hour|hr|h)$/.exec(rate);
  const capacity = m ? Number(m[1]) : 0;
  if (!m || capacity < 1) throw new Error(`invalid rate "${rate}" (want e.g. "60/min")`);
  return { capacity, windowMs: UNITS[m[2]] };
}

/** Continuous-refill token bucket. pauseUntil() is the Retry-After hook: while
 *  paused, no takes succeed and msUntilNext reports the pause. */
export class TokenBucket {
  private available: number;
  private lastRefill: number;
  private pausedUntil = 0;

  constructor(private capacity: number, private windowMs: number) {
    this.available = capacity;
    this.lastRefill = Date.now();
  }

  private refill(now: number): void {
    if (now <= this.lastRefill) return;
    this.available = Math.min(this.capacity, this.available + ((now - this.lastRefill) * this.capacity) / this.windowMs);
    this.lastRefill = now;
  }

  pauseUntil(ts: number): void {
    this.pausedUntil = Math.max(this.pausedUntil, ts);
  }

  tryTake(now = Date.now()): boolean {
    if (now < this.pausedUntil) return false;
    this.refill(now);
    if (this.available < 1) return false;
    this.available -= 1;
    return true;
  }

  msUntilNext(now = Date.now()): number {
    const pause = Math.max(0, this.pausedUntil - now);
    this.refill(now);
    const need = this.available >= 1 ? 0 : ((1 - this.available) * this.windowMs) / this.capacity;
    return Math.ceil(Math.max(pause, need));
  }

  /** Briefly wait for a token, bounded by the caller's budget (the request timeout). */
  async acquire(maxWaitMs: number): Promise<boolean> {
    const deadline = Date.now() + maxWaitMs;
    for (;;) {
      const now = Date.now();
      if (this.tryTake(now)) return true;
      const wait = Math.min(this.msUntilNext(now), deadline - now);
      if (wait <= 0) return false;
      await new Promise((r) => setTimeout(r, Math.min(wait + 1, 250)));
    }
  }
}

/** Consecutive-failure circuit breaker: closed → open (threshold hit) →
 *  half-open (cooldown elapsed, one probe) → closed | open. The transition
 *  return values let the engine emit gateway-health exactly once per change. */
export class Breaker {
  private failures = 0;
  private openedAt = 0;
  private probing = false;
  private _state: "closed" | "open" | "half-open" = "closed";

  constructor(private threshold: number, private cooldownMs: number) {}

  get state(): "closed" | "open" | "half-open" {
    return this._state;
  }

  tryPass(now = Date.now()): boolean {
    if (this._state === "closed") return true;
    if (this._state === "open" && now - this.openedAt >= this.cooldownMs) this._state = "half-open";
    if (this._state === "half-open" && !this.probing) {
      this.probing = true;
      return true;
    }
    return false;
  }

  recordSuccess(): "closed" | null {
    const reopened = this._state !== "closed";
    this.failures = 0;
    this.probing = false;
    this._state = "closed";
    return reopened ? "closed" : null;
  }

  recordFailure(now = Date.now()): "opened" | null {
    if (this._state === "half-open") {
      this.probing = false;
      this._state = "open";
      this.openedAt = now;
      return "opened";
    }
    if (this._state === "open") return null;
    this.failures += 1;
    if (this.failures >= this.threshold) {
      this._state = "open";
      this.openedAt = now;
      this.failures = 0;
      return "opened";
    }
    return null;
  }
}

/** Counting semaphore — the per-provider concurrency cap. */
export class Semaphore {
  private active = 0;
  private queue: (() => void)[] = [];

  constructor(private limit: number) {}

  async acquire(): Promise<() => void> {
    if (this.active >= this.limit) await new Promise<void>((r) => this.queue.push(r));
    this.active += 1;
    let released = false;
    return () => {
      if (released) return;
      released = true;
      this.active -= 1;
      this.queue.shift()?.();
    };
  }
}
```

```ts
// in data/_platform/gateways.sqlite — `links` is the secrets links shape one
// level deeper (per alias), `config_values` holds plain per-connection values,
// `oauth_tokens` holds AES-256-GCM ciphertext over the token JSON (the

// each app's own db (services/gateways.ts). Breaker/bucket state is in-memory
// only (gatewayEngine.ts) — a restart forgives.

import path from "node:path";

import BetterSqlite3 from "better-sqlite3";
import type { Config } from "./config.js";

  constructor(message?: string) {

// ---------- secret-slot links (the grant, spec §3/§8) ----------

export function setGatewayLink(appId: string, alias: string, slot: string, slug: string): void {
  if (!getSecretMeta(slug)) throw new GatewaysNotFoundError(`unknown secret "${slug}"`);
  store()
    .prepare(
      `INSERT INTO links (app_id, alias, slot, slug, linked_at) VALUES (?, ?, ?, ?, ?)
       ON CONFLICT(app_id, alias, slot) DO UPDATE SET slug = excluded.slug, linked_at = excluded.linked_at`
    )
    .run(appId, alias, slot, slug, Date.now());
}

export function deleteGatewayLink(appId: string, alias: string, slot: string): boolean {
  return store().prepare("DELETE FROM links WHERE app_id = ? AND alias = ? AND slot = ?").run(appId, alias, slot).changes > 0;
}

/** Soft reference: the linked secret may since have been deleted from the
 *  catalog — that reads as undefined, i.e. the slot is pending again. */
export function getGatewayLink(appId: string, alias: string, slot: string): { slug: string; label: string } | undefined {
  const row = store()
    .prepare("SELECT slug FROM links WHERE app_id = ? AND alias = ? AND slot = ?")
    .get(appId, alias, slot) as { slug: string } | undefined;
  if (!row) return undefined;

  return meta ? { slug: meta.slug, label: meta.label } : undefined;

    )

}

  const { ciphertext, nonce } = encryptValue(key(), JSON.stringify(t));
  store()
    .prepare(

         ciphertext = excluded.ciphertext, nonce = excluded.nonce,

// ---------- wholesale-registration cleanup (spec §5) ----------

export function pruneGatewayConnections(appId: string, keptAliases: Set<string>): void {
  const s = store();
  const aliases = new Set<string>();
  for (const table of ["links", "config_values", "oauth_tokens"]) {
    const rows = s.prepare(`SELECT DISTINCT alias FROM ${table} WHERE app_id = ?`).all(appId) as { alias: string }[];
    for (const { alias } of rows) aliases.add(alias);
  }
  const txn = s.transaction(() => {
```

```ts
// The gateways service (spec 2026-07-10-gateways): apps consume external
// providers through a host-side door. Manifests live on disk
// (gatewayManifests.ts), connection state in the platform store
// (gatewaysStore.ts), declarations here in the app's own db
// (the secrets _secret_slots pattern) — an app's `src/gateways.ts` aliases,
// registered wholesale per successful worker boot.
import fs from "node:fs";
import path from "node:path";
import type Database from "better-sqlite3";
import { getAppDb } from "../db.js";
import { isValidAppId } from "../registry.js";
import type { Config } from "../config.js";
import { emitLog } from "../logger.js";
import { emitGatewayChange } from "../gatewayEvents.js";
import { GatewaysError, pruneGatewayConnections } from "../gatewaysStore.js";
import { PROVIDER_ID_RE } from "../gatewayManifests.js";

export const CATALOG_NAME = "gateways";

export const ALIAS_RE = /^[a-z0-9_]+$/;

export interface UseDef {
  provider: string;
  description: string | null;
}

// ---------- declarations (per-app db) ----------

export function getUsesDb(dataDir: string, appId: string): Database.Database {
  return getAppDb(dataDir, appId);
}

function validateUseDef(alias: string, raw: unknown): UseDef {
  const r = raw as { provider?: unknown; description?: unknown } | null;
  if (!r || typeof r !== "object") throw new GatewaysError(`"${alias}" is not a gateway declaration`);
  if (typeof r.provider !== "string" || !PROVIDER_ID_RE.test(r.provider) || r.provider.length > 64) {
    throw new GatewaysError(`"${alias}" needs a valid provider id (lowercase letters, digits, dashes)`);
  }
  const description = typeof r.description === "string" && r.description.trim() ? r.description : null;
  return { provider: r.provider, description };
}

// Wholesale per successful boot (spec §5): aliases absent from the manifest
// are removed and their links/config/tokens pruned; a bad def registers with
// its error and never poisons siblings.
export function applyGatewaysManifest(cfg: Config, appId: string, uses: Record<string, unknown>, now: number): void {
  const db = getUsesDb(cfg.dataDir, appId);
  db.exec(
    `CREATE TABLE IF NOT EXISTS _gateway_uses (
      alias         TEXT PRIMARY KEY,
      def           TEXT,          -- JSON UseDef; NULL when the declaration failed
      error         TEXT,          -- per-alias declaration error (spec §5)
      registered_at INTEGER NOT NULL
    );`
  );
  const kept = new Set<string>();
  const txn = db.transaction(() => {
    for (const [alias, raw] of Object.entries(uses)) {
      if (typeof alias !== "string" || !ALIAS_RE.test(alias) || alias.length > 64) continue;
      kept.add(alias);
      let def: UseDef | null = null, error: string | null = null;
      try {
        def = validateUseDef(alias, raw);
      } catch (e) {
        error = e instanceof Error ? e.message : String(e);
      }
      db.prepare(
        `INSERT INTO _gateway_uses (alias, def, error, registered_at)
         VALUES (@alias, @def, @error, @now)
         ON CONFLICT(alias) DO UPDATE SET def = excluded.def, error = excluded.error, registered_at = excluded.registered_at`
      ).run({ alias, def: def ? JSON.stringify(def) : null, error, now });
    }
    const existing = db.prepare("SELECT alias FROM _gateway_uses").all() as { alias: string }[];
    for (const { alias } of existing) {
      if (!kept.has(alias)) db.prepare("DELETE FROM _gateway_uses WHERE alias = ?").run(alias);
    }
  });
  txn();
  try {
    pruneGatewayConnections(appId, kept);
  } catch {
    // connection state lives in the platform store — if it's degraded, stale
    // rows are harmless (the engine is equally degraded) and re-pruned next boot
  }
}

// The onGatewaysManifest callback: a worker booted and reported its declared
// aliases. A load error is NOT an empty manifest — previous uses survive it.
export function registerGatewaysManifest(cfg: Config, appId: string, uses: Record<string, unknown>, loadError?: string): void {
  if (!isValidAppId(appId)) return; // _dashboard sits outside the app-id grammar
  if (loadError) {
    emitLog("error", "gateways", "gateways module failed to load", { stack: loadError }, appId);
    emitGatewayChange(appId, "*");
    return;
  }
  // Never materialize a data dir for an app that has never used gateways.
  if (Object.keys(uses).length === 0 && !fs.existsSync(path.join(cfg.dataDir, appId, "db.sqlite"))) return;
  applyGatewaysManifest(cfg, appId, uses, Date.now());
  emitGatewayChange(appId, "*"); // declarations changed — dashboard refetches
}

export function listUses(db: Database.Database): { alias: string; def: UseDef | null; error: string | null }[] {
  const hasTable = db.prepare("SELECT 1 FROM sqlite_master WHERE type = 'table' AND name = '_gateway_uses'").get();
  if (!hasTable) return [];
  const rows = db.prepare("SELECT alias, def, error FROM _gateway_uses ORDER BY alias").all() as
    { alias: string; def: string | null; error: string | null }[];
  return rows.map((r) => ({ alias: r.alias, def: r.def ? (JSON.parse(r.def) as UseDef) : null, error: r.error }));
}
```

```ts
function bucketFor(providerId: string, manifest: GatewayManifest, t: Tuning): TokenBucket {
  const rate = manifest.limits?.rate ?? t.rate;
  const cached = buckets.get(providerId);
  if (cached && cached.rate === rate) return cached.bucket;
  let parsed;
  try {
    parsed = parseRate(rate);
  } catch {
    parsed = parseRate("60/min"); // an unparseable settings value degrades to the default
  }
  const bucket = new TokenBucket(parsed.capacity, parsed.windowMs);
  buckets.set(providerId, { rate, bucket });
  return bucket;
}

function breakerFor(providerId: string, t: Tuning): Breaker {

  if (!b) {
    b = new Breaker(t.breakerThreshold, t.breakerCooldownMs);
    breakers.set(providerId, b);
  }
  return b;
}

function semaphoreFor(providerId: string, manifest: GatewayManifest, t: Tuning): Semaphore {

// Resolve a slot the auth recipe (or base_url) references. Missing values are
// "unconfigured" — the person hasn't finished the connection; a degraded
// secret store is "unavailable".
function slotValue(manifest: GatewayManifest, appId: string, alias: string, slot: string): string {
  const def = manifest.slots[slot];
  if (!def) throw new GatewayRequestError("unconfigured", `gateway manifest references undeclared slot "${slot}"`);
  try {
    if (def.kind === "config") {
      const v = getGatewayConfig(appId, alias, slot);
      if (v === undefined) throw new GatewayRequestError("unconfigured", `config slot "${slot}" is not set — set it in the dashboard`);
      return v;
    }
    const link = getGatewayLink(appId, alias, slot);
    if (!link) throw new GatewayRequestError("unconfigured", `secret slot "${slot}" is not linked — link it in the dashboard`);
    return readValueBySlug(link.slug);
  } catch (e) {
    if (e instanceof GatewayRequestError) throw e;
    if (e instanceof SecretsNotFoundError) throw new GatewayRequestError("unconfigured", `secret slot "${slot}" points at a deleted secret`);
    if (e instanceof SecretsUnavailableError) throw new GatewayRequestError("unavailable", e.message);
    throw e;
  }
}

function assembleUrl(manifest: GatewayManifest, appId: string, alias: string, desc: GatewayRequestDescriptor): URL {
  const baseRaw = typeof manifest.base_url === "string"
    ? manifest.base_url
    : slotValue(manifest, appId, alias, manifest.base_url.from_slot);
  let base: URL;
  try {
    base = new URL(baseRaw);
  } catch {
    throw new GatewayRequestError("unconfigured", `gateway base URL "${baseRaw}" is not a valid URL`);
  }
  if (base.protocol !== "https:" && !(base.protocol === "http:" && isPrivateHost(base.hostname))) {
    throw new GatewayRequestError("unconfigured", "gateway base URL must be https (http only for private hosts)");
  }
  if (!desc.path.startsWith("/") || desc.path.includes("://")) {
    throw new GatewaysError("path must be relative and start with /");
  }
  const basePath = base.pathname.replace(/\/$/, "");
  const url = new URL(base.origin + basePath + desc.path);
  // URL construction normalized any ../ segments — the resolved path must
  // still live under the base path (egress by construction, spec §2).
  if (url.origin !== base.origin || !(url.pathname === basePath || url.pathname.startsWith(basePath + "/") || basePath === "")) {
    throw new GatewaysError("path escapes the gateway base URL");
  }
  for (const [k, v] of Object.entries(desc.query ?? {})) url.searchParams.set(k, v);
  return url;
}

// Injects credentials per the auth recipe. Returns the redaction list —
// every injected value, masked in anything captured. Recipe-owned headers/
// params win: a descriptor that tries to set one is rejected, not overwritten.
async function injectAuth(
  providerId: string, manifest: GatewayManifest, appId: string, alias: string,
  url: URL, headers: Record<string, string>
): Promise<string[]> {
  const ownedHeader = (name: string) => {
    for (const k of Object.keys(headers)) {
      if (k.toLowerCase() === name.toLowerCase()) {
        throw new GatewaysError(`the gateway owns the "${name}" header`);
      }
    }
  };
  const a = manifest.auth;
  if (a.kind === "none") return [];
  if (a.kind === "api_key") {
    const v = slotValue(manifest, appId, alias, a.slot);
    if (a.in === "query") {
      if (url.searchParams.has(a.param!)) throw new GatewaysError(`the gateway owns the "${a.param}" query param`);
      url.searchParams.set(a.param!, v);
    } else {
      ownedHeader(a.header!);
      headers[a.header!] = v;
    }
    return [v];
  }
  if (a.kind === "bearer") {
    ownedHeader("authorization");
    const v = slotValue(manifest, appId, alias, a.slot);
    headers["authorization"] = `Bearer ${v}`;
    return [v];
  }
  if (a.kind === "basic") {
    ownedHeader("authorization");
    const user = slotValue(manifest, appId, alias, a.username_slot);
    const pass = slotValue(manifest, appId, alias, a.password_slot);
    headers["authorization"] = `Basic ${Buffer.from(`${user}:${pass}`).toString("base64")}`;
    return [user, pass];
  }
  // oauth2 — Task 8's module provides tokens (and transparent refresh).
  ownedHeader("authorization");
  if (!oauthTokenProvider) throw new GatewayRequestError("unconfigured", "OAuth is not available");
  const { token, redact } = await oauthTokenProvider(providerId, manifest, appId, alias);
  headers["authorization"] = `Bearer ${token}`;
  return [token, ...redact];
}

async function readCapped(res: Response, cap: number): Promise<Buffer> {
  const reader = res.body?.getReader();
  if (!reader) return Buffer.alloc(0);
  const chunks: Uint8Array[] = [];
  let total = 0;
  for (;;) {
    const { done, value } = await reader.read();
    if (done) break;
    total += value.byteLength;
    if (total > cap) {
      await reader.cancel().catch(() => {});
      throw new GatewayRequestError("too_large", `response exceeds ${cap} bytes`);
    }
    chunks.push(value);
  }
  return Buffer.concat(chunks);
}

function scrub(s: string, redact: string[]): string {
  let out = s;
  for (const v of redact) {
    if (v) out = out.split(v).join("•••");
  }
  return out.slice(0, CAPTURE_TRUNCATE);
}

function parseRetryAfter(h: string | null, now: number): number | null {
  if (!h) return null;
  const secs = Number(h);
  if (Number.isFinite(secs) && secs > 0) return now + Math.min(secs * 1000, RETRY_AFTER_PAUSE_CAP_MS);
  const date = Date.parse(h);
  if (!Number.isNaN(date) && date > now) return Math.min(date, now + RETRY_AFTER_PAUSE_CAP_MS);
  return null;
}

export async function executeGatewayRequest(
  appId: string, alias: string, desc: GatewayRequestDescriptor
): Promise<GatewayResponseEnvelope> {
  if (!cfgRef) throw new GatewayRequestError("unavailable", "gateway engine not initialized");
  const use = listUses(getUsesDb(cfgRef.dataDir, appId)).find((u) => u.alias === alias);
  if (!use) throw new GatewaysNotFoundError(`unknown gateway alias "${alias}"`);
  if (use.error || !use.def) throw new GatewayRequestError("unconfigured", use.error ?? "invalid gateway declaration");
  const providerId = use.def.provider;
  const entry = getGatewayEntry(providerId);
  if (!entry) {
    throw new GatewayRequestError("unconfigured", `no gateway "${providerId}" — author gateways/${providerId}/manifest.json`);
  }
  if (!entry.manifest) throw new GatewayRequestError("unconfigured", `gateway manifest invalid: ${entry.error}`);
  const manifest = entry.manifest;
  const t = tuning();
  const timeoutMs = Math.min(desc.timeoutMs ?? manifest.limits?.timeout_ms ?? t.timeoutMs, HARD_TIMEOUT_CAP_MS);
  const source = `gateway:${providerId}`;
  const healthKey = `${appId}\n${alias}`;

  const record = (
    level: "info" | "warn" | "error", outcome: string, status: number | null,
    durationMs: number, extra: Record<string, unknown> = {}
  ) => {
    emitLog(level, source, `${desc.method} ${desc.path} → ${status ?? outcome} (${durationMs} ms)`, {
      provider: providerId, alias, method: desc.method, path: desc.path,
      status: status ?? undefined, outcome, durationMs, ...extra,
    }, appId);
  };

  const breaker = breakerFor(providerId, t);
  if (!breaker.tryPass()) {
    record("error", "breaker_open", null, 0);
    throw new GatewayRequestError("breaker_open", `the ${manifest.name} gateway's circuit breaker is open`);
  }
  const release = await semaphoreFor(providerId, manifest, t).acquire();
  const started = Date.now();
  try {
    if (!(await bucketFor(providerId, manifest, t).acquire(timeoutMs))) {
      record("warn", "rate_limited", null, Date.now() - started);
      throw new GatewayRequestError("rate_limited", `the ${manifest.name} gateway's rate limit is exhausted`);
    }
    const headers: Record<string, string> = {};
    for (const [k, v] of Object.entries(desc.headers ?? {})) {
      const lk = k.toLowerCase();
      if (lk === "host" || lk === "cookie") continue; // never caller-suppliable
      headers[lk] = v;
    }
    const url = assembleUrl(manifest, appId, alias, desc);
    const redact = await injectAuth(providerId, manifest, appId, alias, url, headers);
    const body = desc.bodyBase64 !== undefined ? Buffer.from(desc.bodyBase64, "base64")
      : desc.body !== undefined ? desc.body : undefined;
    let res: Response;
    try {
      res = await fetch(url, {
        method: desc.method,
        headers,
        body: body as BodyInit | undefined,
        redirect: "manual", // a redirect off-base must not be followed silently
        signal: AbortSignal.timeout(timeoutMs),
      });
    } catch (e) {
      const timedOut = e instanceof Error && e.name === "TimeoutError";
      const opened = breaker.recordFailure();
      if (opened) emitGatewayHealth(PLATFORM_NS, { provider: providerId, breaker: "open" });
      const outcome = timedOut ? "timeout" : "network";
      record("error", outcome, null, Date.now() - started);
      throw new GatewayRequestError(timedOut ? "timeout" : "network", e instanceof Error ? e.message : String(e));
    }
    const bytes = await readCapped(res, manifest ? (t.maxResponseBytes) : t.maxResponseBytes);
    const durationMs = Date.now() - started;

    // Breaker accounting: 5xx/network are provider failures; everything else
    // (incl. 4xx) is a completed conversation (spec §9).
    if (res.status >= 500) {
      const opened = breaker.recordFailure();
      if (opened) emitGatewayHealth(PLATFORM_NS, { provider: providerId, breaker: "open" });
    } else {
      const closed = breaker.recordSuccess();
      if (closed) emitGatewayHealth(PLATFORM_NS, { provider: providerId, breaker: "closed" });
    }
    // Connection health: 401/403 mark this connection, one event per transition.
    if (res.status === 401 || res.status === 403) {
      if (!unhealthy.has(healthKey)) {
        unhealthy.add(healthKey);
        emitGatewayHealth(appId, { alias, provider: providerId, status: "unhealthy" });
      }
    } else if (res.status < 400 && unhealthy.delete(healthKey)) {
      emitGatewayHealth(appId, { alias, provider: providerId, status: "ok" });
    }
    // Retry-After: pause the shared bucket so nobody hammers a throttling provider.
    if (res.status === 429) {
      const until = parseRetryAfter(res.headers.get("retry-after"), Date.now());
      if (until) bucketFor(providerId, manifest, t).pauseUntil(until);
    }

    const outHeaders: Record<string, string> = {};
    res.headers.forEach((v, k) => {
      if (k.toLowerCase() !== "set-cookie") outHeaders[k.toLowerCase()] = v;
    });
    const contentType = res.headers.get("content-type") ?? "";
    const textual = TEXTUAL.test(contentType);
    const envelope: GatewayResponseEnvelope = {
      status: res.status,
      headers: outHeaders,
      durationMs,
      ...(textual ? { body: bytes.toString("utf8") } : { bodyBase64: bytes.toString("base64") }),
    };

    const level = res.status >= 500 ? "error" : res.status >= 400 ? "warn" : "info";
    const outcome = res.status >= 500 ? "server_error" : res.status >= 400 ? "client_error" : "ok";
    const extra: Record<string, unknown> = {
      reqBytes: body === undefined ? 0 : Buffer.byteLength(body as string | Buffer),
      resBytes: bytes.byteLength,
    };
    if (t.captureBodies) {
      if (typeof body === "string") extra.requestBody = scrub(body, redact);
      if (textual) extra.responseBody = scrub(bytes.toString("utf8"), redact);
    }
    record(level, outcome, res.status, durationMs, extra);
    return envelope;
  } catch (e) {
    if (e instanceof GatewayRequestError && (e.reason === "unconfigured" || e.reason === "needs_reauth" || e.reason === "unavailable")) {
      record("warn", e.reason, null, Date.now() - started);
    }
    if (e instanceof GatewayRequestError && e.reason === "too_large") {
      record("error", "too_large", null, Date.now() - started);
    }
    throw e;
  } finally {
    release();
  }
}
```

```ts
/** One app's connection docs — slot state, oauth state, derived status. */
export function connectionDocsForApp(cfg: Config, appId: string) {
  return listUses(getUsesDb(cfg.dataDir, appId)).map(({ alias, def, error }) => {
    const entry = def ? getGatewayEntry(def.provider) : undefined;
    const m = entry?.manifest ?? null;
    const slots = m
      ? Object.entries(m.slots).map(([slot, d]) => {
          if (d.kind === "secret") {
            const secret = getGatewayLink(appId, alias, slot) ?? null;
            return {
              slot, kind: d.kind, label: d.label, description: d.description ?? null,
              optional: d.optional ?? false,
              status: secret ? ("linked" as const) : ("pending" as const), secret, value: null,
            };
          }
          const value = getGatewayConfig(appId, alias, slot) ?? null;
          return {
            slot, kind: d.kind, label: d.label, description: d.description ?? null,
            optional: d.optional ?? false,
            status: value !== null ? ("set" as const) : ("pending" as const), secret: null, value,
          };
        })
      : [];
    const oauth = m?.auth.kind === "oauth2" ? { status: oauthState(appId, alias) } : null;
    const declError =
      error ??
      (def && !entry
        ? `no gateway "${def.provider}" — ask your agent to author gateways/${def.provider}/manifest.json`
        : def && entry && entry.error
          ? `gateway manifest invalid: ${entry.error}`
          : null);
    let status: "error" | "needs_setup" | "needs_reauth" | "unhealthy" | "connected";
    if (declError) status = "error";
    else if (slots.some((s) => !s.optional && s.status === "pending") || oauth?.status === "none") status = "needs_setup";
    else if (oauth?.status === "needs_reauth") status = "needs_reauth";
    else if (getConnectionHealth(appId, alias) === "unhealthy") status = "unhealthy";
    else status = "connected";
    return {
      alias, provider: def?.provider ?? null, providerName: m?.name ?? def?.provider ?? null,
      description: def?.description ?? null, error: declError, status, slots, oauth,
    };
  });
}
```

```ts
// OAuth 2.0 for gateways (spec 2026-07-10-gateways §7): authorization-code +
// PKCE with zero dependencies — authorize-URL construction, state/verifier via
// node:crypto, token exchange/refresh as plain fetch POSTs. Tokens are
// encrypted at rest (gatewaysStore) and never leave the runtime process; the
// engine injects them via the token-provider seam. The agent never handles
// tokens — the person clicks Connect in the dashboard.
import { createHash, randomBytes } from "node:crypto";
import type { Config } from "./config.js";
import type { GatewayManifest } from "./gatewayManifests.js";
import { GatewayRequestError, _setOauthTokenProvider } from "./gatewayEngine.js";
import { getGatewayEntry } from "./gatewayManifests.js";
import {
  GatewaysError, getGatewayConfig, getGatewayLink, loadOauthTokens, saveOauthTokens, setNeedsReauth, oauthState,
} from "./gatewaysStore.js";
import { readValueBySlug } from "./secretsStore.js";
import { getUsesDb, listUses } from "./services/gateways.js";
import { emitGatewayChange, emitGatewayHealth } from "./gatewayEvents.js";

const PENDING_TTL_MS = 10 * 60_000;
const EXPIRY_SKEW_MS = 30_000;

interface Pending {
  appId: string;
  alias: string;
  providerId: string;
  verifier: string | null;
  createdAt: number;
}

let cfgRef: Config | null = null;
const pending = new Map<string, Pending>(); // state → Pending, in-memory only

type Oauth2 = Extract<GatewayManifest["auth"], { kind: "oauth2" }>;

function oauthManifest(appId: string, alias: string): { providerId: string; manifest: GatewayManifest; auth: Oauth2 } {
  if (!cfgRef) throw new GatewayRequestError("unavailable", "oauth not initialized");
  const use = listUses(getUsesDb(cfgRef.dataDir, appId)).find((u) => u.alias === alias);
  if (!use?.def) throw new GatewayRequestError("unconfigured", `unknown gateway alias "${alias}"`);
  const entry = getGatewayEntry(use.def.provider);
  if (!entry?.manifest) throw new GatewayRequestError("unconfigured", `gateway "${use.def.provider}" is missing or invalid`);
  if (entry.manifest.auth.kind !== "oauth2") throw new GatewaysError(`gateway "${use.def.provider}" does not use OAuth`);
  return { providerId: use.def.provider, manifest: entry.manifest, auth: entry.manifest.auth };
}

function clientId(auth: Oauth2, appId: string, alias: string): string {
  const v = getGatewayConfig(appId, alias, auth.client_id_slot);
  if (!v) throw new GatewayRequestError("unconfigured", `set the "${auth.client_id_slot}" config slot before connecting`);
  return v;
}

function clientSecret(auth: Oauth2, appId: string, alias: string): string | null {
  if (!auth.client_secret_slot) return null;
  const link = getGatewayLink(appId, alias, auth.client_secret_slot);
  if (!link) throw new GatewayRequestError("unconfigured", `link the "${auth.client_secret_slot}" secret slot before connecting`);
  return readValueBySlug(link.slug);
}

function redirectUri(): string {
  if (!cfgRef) throw new GatewayRequestError("unavailable", "oauth not initialized");
  return `${cfgRef.baseUrl}/api/gateways/oauth/callback`;
}

function sweepPending(now: number): void {
  for (const [state, p] of pending) {
    if (now - p.createdAt > PENDING_TTL_MS) pending.delete(state);
  }
}

export function initGatewayOauth(cfg: Config): void {
  cfgRef = cfg;
  pending.clear();
  _setOauthTokenProvider(tokenProvider);
}

export function resetGatewayOauthForTest(): void {
  cfgRef = null;
  pending.clear();
  _setOauthTokenProvider(null);
}

export function startOauth(appId: string, alias: string): { authorizeUrl: string } {
  const { providerId, auth } = oauthManifest(appId, alias);
  const id = clientId(auth, appId, alias);
  clientSecret(auth, appId, alias); // fail unconfigured now, not at the callback
  const now = Date.now();
  sweepPending(now);
  const state = randomBytes(16).toString("hex");
  const usePkce = auth.pkce !== false;
  const verifier = usePkce ? randomBytes(32).toString("base64url") : null;
  pending.set(state, { appId, alias, providerId, verifier, createdAt: now });
  const u = new URL(auth.authorization_url);
  u.searchParams.set("response_type", "code");
  u.searchParams.set("client_id", id);
  u.searchParams.set("redirect_uri", redirectUri());
  u.searchParams.set("state", state);
  if (auth.scopes?.length) u.searchParams.set("scope", auth.scopes.join(" "));
  if (verifier) {
    u.searchParams.set("code_challenge", createHash("sha256").update(verifier).digest("base64url"));
    u.searchParams.set("code_challenge_method", "S256");
  }
  return { authorizeUrl: u.toString() };
}

async function tokenPost(auth: Oauth2, params: Record<string, string>): Promise<{ access_token: string; refresh_token?: string; expires_in?: number }> {
  const res = await fetch(auth.token_url, {
    method: "POST",
    headers: { "Content-Type": "application/x-www-form-urlencoded" },
    body: new URLSearchParams(params).toString(),
    signal: AbortSignal.timeout(15_000),
  });
  const body = (await res.json().catch(() => null)) as { access_token?: string; refresh_token?: string; expires_in?: number; error?: string } | null;
  if (!res.ok || !body?.access_token) {
    throw new GatewaysError(`token request failed: ${body?.error ?? res.status}`);
  }
  return body as { access_token: string; refresh_token?: string; expires_in?: number };
}

export async function handleOauthCallback(query: { code?: string; state?: string; error?: string }): Promise<{ appId: string; alias: string }> {
  sweepPending(Date.now());
  const p = query.state ? pending.get(query.state) : undefined;
  if (query.state) pending.delete(query.state); // single-use, success or not
  if (!p) throw new GatewaysError("this connection request is unknown or expired — go back and click Connect again");
  if (query.error || !query.code) throw new GatewaysError(`the provider declined: ${query.error ?? "no code returned"}`);
  const { auth } = oauthManifest(p.appId, p.alias);
  const params: Record<string, string> = {
    grant_type: "authorization_code",
    code: query.code,
    redirect_uri: redirectUri(),
    client_id: clientId(auth, p.appId, p.alias),
  };
  const secret = clientSecret(auth, p.appId, p.alias);
  if (secret) params.client_secret = secret;
  if (p.verifier) params.code_verifier = p.verifier;
  const t = await tokenPost(auth, params);
  saveOauthTokens(p.appId, p.alias, {
    accessToken: t.access_token,
    ...(t.refresh_token ? { refreshToken: t.refresh_token } : {}),
    ...(t.expires_in ? { expiresAt: Date.now() + t.expires_in * 1000 } : {}),
  });
  emitGatewayChange(p.appId, p.alias);
  return { appId: p.appId, alias: p.alias };
}

// The engine's token provider (spec §7): stored token, refreshed transparently
// when expired; a failed refresh flips the connection to needs-reauth.
async function tokenProvider(
  providerId: string, manifest: GatewayManifest, appId: string, alias: string
): Promise<{ token: string; redact: string[] }> {
  const auth = manifest.auth as Oauth2;
  if (oauthState(appId, alias) === "needs_reauth") {
    throw new GatewayRequestError("needs_reauth", `reconnect the ${manifest.name} gateway in the dashboard`);
  }
  const tokens = loadOauthTokens(appId, alias);
  if (!tokens) throw new GatewayRequestError("unconfigured", `connect the ${manifest.name} gateway in the dashboard`);
  const redact = [tokens.refreshToken ?? ""].filter(Boolean);
  const expired = tokens.expiresAt !== undefined && tokens.expiresAt - EXPIRY_SKEW_MS <= Date.now();
  if (!expired) return { token: tokens.accessToken, redact };
  if (!tokens.refreshToken) {
    setNeedsReauth(appId, alias, true);
    emitGatewayHealth(appId, { alias, provider: providerId, status: "needs_reauth" });
    throw new GatewayRequestError("needs_reauth", `the ${manifest.name} token expired and no refresh token exists — reconnect`);
  }
  try {
    const params: Record<string, string> = {
      grant_type: "refresh_token",
      refresh_token: tokens.refreshToken,
      client_id: clientId(auth, appId, alias),
    };
    const secret = clientSecret(auth, appId, alias);
    if (secret) params.client_secret = secret;
    const t = await tokenPost(auth, params);
    saveOauthTokens(appId, alias, {
      accessToken: t.access_token,
      refreshToken: t.refresh_token ?? tokens.refreshToken, // rotate when offered
      ...(t.expires_in ? { expiresAt: Date.now() + t.expires_in * 1000 } : {}),
    });
    return { token: t.access_token, redact: [t.refresh_token ?? tokens.refreshToken] };
  } catch {
    setNeedsReauth(appId, alias, true);
    emitGatewayHealth(appId, { alias, provider: providerId, status: "needs_reauth" });
    throw new GatewayRequestError("needs_reauth", `the ${manifest.name} session could not be refreshed — reconnect in the dashboard`);
  }
}
```

```ts
// The declaration side of the gateways service (spec 2026-07-10-gateways §5):
// alias builders + a thin validator/tagger. appWorkerEntry scans the built
// src/gateways.ts DEFAULT export for the __lodekitGateways marker and posts
// `uses` as the gateways manifest; full validation is runtime-side. The call
// surface is the SDK singleton's `gateways` handle (client.ts) — server-only.

export interface GatewayUse {
  provider: string;
  description?: string;
}

export const gateway = (cfg: GatewayUse): GatewayUse => ({ ...cfg });

export type GatewayUses = Record<string, GatewayUse>;

export type GatewayErrorReason =
  | "unconfigured" | "rate_limited" | "breaker_open" | "needs_reauth"
  | "timeout" | "too_large" | "network" | "unavailable";

/** Thrown by gateway calls. `unconfigured`/`needs_reauth` mean the person
 * finishes the connection in the dashboard — render a "configure me" state;
 * the transient reasons are fair game for a task's own retry policy. */
export class GatewayError extends Error {
  constructor(
    public readonly reason: GatewayErrorReason,
    message?: string
  ) {
    super(message ?? `gateway ${reason}`);
    this.name = "GatewayError";
  }
}

export interface DefinedGateways<G extends GatewayUses> {
  __lodekitGateways: true;
  uses: G;
}

const ALIAS_RE = /^[a-z0-9_]+$/;
const PROVIDER_ID_RE = /^[a-z0-9-]+$/;

export function defineGateways<G extends GatewayUses>(uses: G): DefinedGateways<G> {
  for (const [alias, u] of Object.entries(uses)) {
    if (!ALIAS_RE.test(alias) || alias.length > 64) {
      throw new Error(`defineGateways(): invalid alias "${alias}" (snake_case, max 64)`);
    }
    if (typeof u?.provider !== "string" || !PROVIDER_ID_RE.test(u.provider) || u.provider.length > 64) {
      throw new Error(`defineGateways(): "${alias}" needs a valid provider id (lowercase letters, digits, dashes)`);
    }
  }
  return { __lodekitGateways: true, uses };
}
```

```ts
  // The gateways door (spec §6): all external traffic flows through the
  // runtime — the worker never holds a credential. Plain fetch (not hc): the
  // token header decides access and the envelope carries arbitrary bodies.
  const gatewayCall = async (alias: string, desc: { method: string; path: string } & GatewayRequestOpts): Promise<GatewayResponse> => {
    const token =
      typeof window === "undefined" && typeof process !== "undefined"
        ? process.env?.LODEKIT_WORKER_TOKEN
        : undefined;
    if (!token) throw new Error("gateways are server-only; call from a server function or task");
    const payload: Record<string, unknown> = { method: desc.method, path: desc.path };
    if (desc.query) {
      payload.query = Object.fromEntries(Object.entries(desc.query).map(([k, v]) => [k, String(v)]));
    }
    const headers: Record<string, string> = {};
    for (const [k, v] of Object.entries(desc.headers ?? {})) headers[k.toLowerCase()] = v;
    if (desc.body !== undefined) {
      if (typeof desc.body === "string") payload.body = desc.body;
      else if (desc.body instanceof Uint8Array) payload.bodyBase64 = Buffer.from(desc.body).toString("base64");
      else {
        payload.body = JSON.stringify(desc.body);
        headers["content-type"] ??= "application/json";
      }
    }
    if (Object.keys(headers).length > 0) payload.headers = headers;
    if (desc.timeoutMs !== undefined) payload.timeoutMs = desc.timeoutMs;
    const r = await fetch(`${baseUrl}/api/apps/${appId}/gateways/${encodeURIComponent(alias)}/request`, {
      method: "POST",
      headers: { "Content-Type": "application/json", "x-lodekit-worker-token": token },
      body: JSON.stringify(payload),
    });
    const data = (await r.json().catch(() => null)) as
      | { status: number; headers: Record<string, string>; body?: string; bodyBase64?: string; durationMs: number }
      | { error?: string; reason?: GatewayErrorReason }
      | null;
    if (!r.ok) {
      const err = data as { error?: string; reason?: GatewayErrorReason } | null;
      if (err?.reason) throw new GatewayError(err.reason, err.error);
      throw new Error(err?.error ?? `gateway request failed: ${r.status}`);
    }
    const env = data as { status: number; headers: Record<string, string>; body?: string; bodyBase64?: string };
    const text = () =>
      Promise.resolve(env.body ?? (env.bodyBase64 ? Buffer.from(env.bodyBase64, "base64").toString("utf8") : ""));
    return {
      status: env.status,
      ok: env.status >= 200 && env.status < 300,
      headers: env.headers,
      text,
      json: async <T>() => JSON.parse(await text()) as T,
    };
  };

  const handleCache = new Map<string, ConnectionHandle>();
  const handleFor = (alias: string): ConnectionHandle => {
    let h = handleCache.get(alias);
    if (!h) {
      const call = (method: string) => (path: string, opts: GatewayRequestOpts = {}) =>
        gatewayCall(alias, { method, path, ...opts });
      h = {
        get: call("GET"), post: call("POST"), put: call("PUT"),
        patch: call("PATCH"), delete: call("DELETE"),
        request: (desc) => gatewayCall(alias, desc),
      };
      handleCache.set(alias, h);
    }
    return h;
  };
  const gateways: Gateways = new Proxy({} as Gateways, {
    get: (_t, alias) => (typeof alias === "string" ? handleFor(alias) : undefined),
```

```tsx
function ConnectionRow({ c, providerId, invalidate }: { c: ConnectionDoc; providerId: string; invalidate: () => void }) {

    queryKey: ["secrets", "_platform"],

  });

    const res = await fn();
    if (!res.ok) { setError((await res.json().catch(() => null))?.error ?? res.statusText); return; }
    setError(null); setCreating(null); setNewLabel(""); setNewValue("");
```

````markdown
## Gateways

**You build an integration by using a gateway to the provider — reuse one if
it exists, author one if not.** When the person asks to "integrate with X" or
"get data from X", the gateway is how: a declarative manifest the runtime
enforces. Your app's server code calls through it; the runtime injects the
credentials — app code never holds a key.

The decision flow:

1. **Check existing gateways first**: `lodekit_gateways` (or list
   `<root>/gateways/`). If a gateway for the provider exists, just declare a
   connection (step 3).
2. **Author a manifest** only when none fits:
   `gateways/<provider-id>/manifest.json` + a `favicon.svg`/`png` beside it.
   HTTPS only for public hosts (`http:` is allowed only toward
   localhost/private hosts, e.g. a local Home Assistant).

```json
{
  "name": "OpenWeatherMap",
  "website": "https://openweathermap.org",
  "base_url": "https://api.openweathermap.org",
  "auth": { "kind": "api_key", "in": "query", "param": "appid", "slot": "api_key" },
  "slots": { "api_key": { "kind": "secret", "label": "API key" } },
  "limits": { "rate": "60/min" }
}
```

Auth kinds: `none`, `api_key` (query or header), `bearer`, `basic`, `oauth2`
(authorization/token URLs + a `client_id` config slot; the person clicks
Connect in the dashboard). Slots are `secret` (the person links a catalog
secret) or `config` (a plain per-connection value — a personal base URL, an
account id).

3. **Declare the connection** in `src/gateways.ts`:

```ts
import { defineGateways, gateway } from "@lodekit/sdk";

export default defineGateways({
  weather: gateway({
    provider: "openweathermap",
    description: "Daily forecast for the watering log.",
  }),
});
```

4. **Call it — only in server functions and tasks** (never browser code):

```ts
import { gateways, GatewayError } from "@lodekit/sdk";

const res = await gateways.weather.get("/data/2.5/forecast", {
  query: { q: "Lisbon", units: "metric" },
});
if (res.ok) {
  const forecast = await res.json();
}
```

Paths are relative — the runtime pins requests under the gateway's base URL.
Failures throw `GatewayError` with a `reason`: `unconfigured`/`needs_reauth`
mean the person finishes the connection in the dashboard (render a
"configure me" state); `rate_limited`/`breaker_open`/`timeout`/`network` are
transient — let the task run fail and its retry policy decide. Every request
is recorded in Logs under `source=gateway:<provider-id>`.

**The polling recipe** (no webhooks exist): a scheduled task calls through
the gateway, writes domain records to the Database, emits an event. Tasks is
the scheduler, the Database is the record, Events is the announcement — no
gateway-side polling machinery exists.

Hard rules:

- **Never ask the person for a credential in chat** — direct them to the
  gateway's page in the dashboard (Gateways → the provider), where they link
  secrets, set config values, and click Connect for OAuth.
- **The agent never handles OAuth tokens.** Connect is a person-only,
  dashboard-only act.
- Don't fetch external APIs directly from app code when a gateway fits —
  the gateway is what gives the person rate limiting, monitoring, and
  key safety.
````

```ts
/** Sky Journal (gateways spec §14): the polling recipe — a scheduled task
 *  calls through the gateway, writes domain records, and the UI reads the
 *  table. Unconfigured is a calm no-op, not a failed run. */
export const weather_log = task({
  cron: "0 7 * * *",
  catchUp: true,
  run: async () => {
    const location = (await settings.get<string>("weather_location")) ?? "Lisbon,pt";
    let res;
    try {
      res = await gateways.weather.get("/data/2.5/forecast", {
        query: { q: location, units: "metric" },
      });
    } catch (e) {
      if (e instanceof GatewayError && (e.reason === "unconfigured" || e.reason === "unavailable")) {
        logs.info("sky journal idle — link an OpenWeatherMap key on the gateway page", { reason: e.reason });
        return;
      }
      throw e; // transient failures fail the run; task retries handle it
    }
    if (!res.ok) {
      logs.warn("weather fetch failed", { status: res.status });
      return;
    }
    const data = await res.json<{
      list: { dt: number; main: { temp_min: number; temp_max: number; humidity: number }; wind: { speed: number }; rain?: Record<string, number> }[];
    }>();
    const day = new Date().toISOString().slice(0, 10);
    const today = data.list.filter((x) => new Date(x.dt * 1000).toISOString().slice(0, 10) === day);
    if (today.length === 0) return;
    const row = {
      day,
      high: Math.max(...today.map((x) => x.main.temp_max)),
      low: Math.min(...today.map((x) => x.main.temp_min)),
      humidity: Math.round(today.reduce((s, x) => s + x.main.humidity, 0) / today.length),
      wind: Math.max(...today.map((x) => x.wind.speed)),
      rained: today.some((x) => Object.values(x.rain ?? {}).some((v) => v > 0)),
      recordedAt: Date.now(),
    };
    await db.insert(weatherLog).values(row).onConflictDoUpdate({ target: weatherLog.day, set: row });
    logs.info("sky journal updated", { day, high: row.high, low: row.low, rained: row.rained });
  },
});
```

```js
function installGateways(showcaseGatewaysDir, lodekitRoot) {
  if (!showcaseGatewaysDir || !fs.existsSync(showcaseGatewaysDir)) return [];
  const installed = [];
  for (const entry of fs.readdirSync(showcaseGatewaysDir, { withFileTypes: true })) {
    if (!entry.isDirectory()) continue;
    const dst = path.join(lodekitRoot, "gateways", entry.name);
    if (fs.existsSync(dst)) continue;
    fs.cpSync(path.join(showcaseGatewaysDir, entry.name), dst, { recursive: true });
    installed.push(entry.name);
  }
  return installed;
}

module.exports = { installShowcase, installGateways };
```
