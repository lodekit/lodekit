# Settings Service (v1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the settings service per `docs/specs/2026-07-07-settings-design.md` — schema-driven, person-editable platform + app settings with per-app service overrides, a dashboard `/settings` page, manager integration, and every hard-coded service default replaced by an effective-value read.

**Architecture:** A new catalog service (`services/settings.ts`: per-app `_lodekit_setting_defs`/`_lodekit_setting_values` tables plus a platform value store at `data/_platform/settings.sqlite`, Hono routers, bus SSE) built on two new pure modules (`settingsSchema.ts` — the closed five-type field grammar and value validation; `platformSettings.ts` — the §6 catalog as code). Apps declare settings in `src/settings.ts` via an SDK `defineSettings()` wrapper; the Start build emits `server/settings.js`; the worker posts a settings manifest on boot (the tasks mechanism, mirrored). Services resolve effective values (app override → platform value → code default) through `getEffective` with a write-invalidated cache. The dashboard gets a schema-driven `/settings` route; the manager subscribes over SSE and applies `start_at_login`/`icon_style`.

**Tech Stack:** TypeScript (tsx, buildless), Hono + zod 4 + `hc` typed RPC, better-sqlite3, the existing event bus (`emitEvent`), TanStack Start dashboard, @lodekit/ui (shadcn/Radix), Electron manager (plain JS + vitest), vitest.

## Global Constraints

- Work on the current branch (`service`), commit per task. Do NOT merge/rebase into `master` — the person integrates. No `Co-Authored-By` trailers.
- Catalog name / URL segment / SDK handle: `settings`. SSE: bus event **type** `settings-change`, emitted via `emitEvent` (envelope wire name `event`), identity-only payload `{ key }`, `ttl: CHANGE_FEED_TTL_S`. NEVER the pre-bus `broadcast(...)` pattern.
- **Stay off the `stack` branch's turf** (`2026-07-07-tasks-change-bus-migration-design.md` is in flight): do not touch `emitTasksChange`'s body, the SDK's `tasks.watch`/`TasksChange`, or the dashboard's `es.addEventListener("tasks-change", …)` block. Settings edits to `services/tasks.ts` are confined to defaults/retention/validation plumbing.
- Setting keys: app keys `^[a-z0-9_]+$` (snake_case, ≤ 64 chars, no dots); platform keys `^[a-z0-9_]+\.[a-z0-9_]+$` (dot-namespaced). Every field requires `label`, `description`, `default`.
- Field types: exactly `boolean | string | number | select | duration` — no additions. Durations use the existing `parseDuration` grammar (`"30s"`, `"10m"`, `"6h"`, `"2d"`).
- Writes are person-only: no `settings.set()` in the SDK, no MCP write tool. Apps read + watch their OWN declared settings only; services resolve service settings internally.
- Only explicit values are persisted (unset = default; reset = DELETE). Hard API caps (100kb body limit, list-limit ceilings 1000/200) stay code — only defaults become settings.
- `scope: "global"` settings (sweep intervals, `tasks.dispatch_poll`, `logs.retention_max_rows`, `events.retention_max_rows`, `general.*`, `appearance.*`) are never per-app overridable; a PUT of a global key on an app route is a 400.
- `_platform` joins `_dashboard` as a reserved id (both fail `isValidAppId` — no collision with the apps tree is possible).
- Follow existing file style exactly: `services/tasks.ts` is the service template, `task.ts` the SDK-wrapper template, `appWorkerEntry.mjs`'s tasks block the manifest template, `eventStore.ts` the platform-singleton template. Chained Hono routers (hc inference), `zValidator` + `validationHook`, `WeakSet` schema-ensure.
- Surgical changes only. Expect trivial rebase conflicts with `stack` in `services/tasks.ts` / `sdk/src/{client,index}.ts` / dashboard `index.tsx` / `roadmap.md` — whichever lands second rebases.

```ts
// packages/runtime/src/settingsSchema.ts
// The closed field grammar for the settings service (spec §4): five types, each
// rendering to exactly one dashboard component. label/description/default are
// REQUIRED — the dashboard never shows an undocumented knob.
import { parseDuration } from "./duration.js";

export interface FieldBase {
  label: string;
  description: string;
  advanced?: boolean;
}
export interface BooleanField extends FieldBase { type: "boolean"; default: boolean }
export interface StringField extends FieldBase { type: "string"; default: string; maxLength?: number; placeholder?: string }
export interface NumberField extends FieldBase { type: "number"; default: number; min?: number; max?: number; step?: number; integer?: boolean }
export interface SelectField extends FieldBase { type: "select"; default: string; options: { value: string; label: string }[] }
export interface DurationField extends FieldBase { type: "duration"; default: string; min?: string; max?: string }
export type SettingField = BooleanField | StringField | NumberField | SelectField | DurationField;

export const APP_KEY_RE = /^[a-z0-9_]+$/;   // bare snake_case; dots are the platform namespace
const TYPES = new Set(["boolean", "string", "number", "select", "duration"]);
const STRING_HARD_CAP = 4_096;

function fail(key: string, why: string): never {
  throw new Error(`setting "${key}": ${why}`);
}

// Declaration-time validation: shape, required copy, constraint sanity, and a
// default that passes its own value validation.
export function validateFieldDef(key: string, raw: unknown): SettingField {
  if (!APP_KEY_RE.test(key) || key.length > 64) fail(key, "invalid key (snake_case, max 64 chars)");
  if (typeof raw !== "object" || raw === null) fail(key, "field must be an object");
  const f = raw as Record<string, unknown>;
  if (typeof f.type !== "string" || !TYPES.has(f.type)) fail(key, `unknown type "${String(f.type)}"`);
  if (typeof f.label !== "string" || !f.label.trim() || f.label.length > 80) fail(key, "label is required (max 80 chars)");
  if (typeof f.description !== "string" || !f.description.trim() || f.description.length > 240) {
    fail(key, "description is required (max 240 chars)");
  }
  if (f.advanced !== undefined && typeof f.advanced !== "boolean") fail(key, "advanced must be a boolean");
  if (f.type === "number") {
    for (const k of ["min", "max", "step"] as const) {
      if (f[k] !== undefined && typeof f[k] !== "number") fail(key, `${k} must be a number`);
    }
    if (f.integer !== undefined && typeof f.integer !== "boolean") fail(key, "integer must be a boolean");
    if (typeof f.min === "number" && typeof f.max === "number" && f.min > f.max) fail(key, "min exceeds max");
  }
  if (f.type === "string") {
    if (f.maxLength !== undefined && (typeof f.maxLength !== "number" || !Number.isInteger(f.maxLength) || f.maxLength < 1)) {
      fail(key, "maxLength must be a positive integer");
    }
    if (f.placeholder !== undefined && typeof f.placeholder !== "string") fail(key, "placeholder must be a string");
  }
  if (f.type === "select") {
    const opts = f.options;
    if (!Array.isArray(opts) || opts.length === 0) fail(key, "options must be a non-empty array");
    const values = new Set<string>();
    for (const o of opts) {
      const opt = o as Record<string, unknown>;
      if (typeof opt?.value !== "string" || !opt.value || typeof opt?.label !== "string" || !opt.label) {
        fail(key, "each option needs a value and a label");
      }
      if (values.has(opt.value as string)) fail(key, `duplicate option value "${opt.value}"`);
      values.add(opt.value as string);
    }
  }
  if (f.type === "duration") {
    for (const k of ["min", "max"] as const) {
      if (f[k] !== undefined) {
        if (typeof f[k] !== "string") fail(key, `${k} must be a duration string`);
        try { parseDuration(f[k] as string); } catch { fail(key, `${k} is not a valid duration`); }
      }
    }
    if (typeof f.min === "string" && typeof f.max === "string" && parseDuration(f.min) > parseDuration(f.max)) {
      fail(key, "min exceeds max");
    }
  }
  const field = f as unknown as SettingField;
  if (!("default" in f)) fail(key, "default is required");
  try {
    validateValue(field, f.default);
  } catch (e) {
    fail(key, `default: ${e instanceof Error ? e.message : String(e)}`);
  }
  return field;
}

// Write-time (and read-drift) validation of a value against its field. Returns
// the value; throws with a person-readable reason.
export function validateValue(field: SettingField, value: unknown): boolean | string | number {
  switch (field.type) {
    case "boolean":
      if (typeof value !== "boolean") throw new Error("expected a boolean");
      return value;
    case "string": {
      if (typeof value !== "string") throw new Error("expected a string");
      const cap = Math.min(field.maxLength ?? STRING_HARD_CAP, STRING_HARD_CAP);
      if (value.length > cap) throw new Error(`at most ${cap} characters`);
      return value;
    }
    case "number":
      if (typeof value !== "number" || !Number.isFinite(value)) throw new Error("expected a number");
      if (field.integer && !Number.isInteger(value)) throw new Error("expected an integer");
      if (field.min !== undefined && value < field.min) throw new Error(`at least ${field.min}`);
      if (field.max !== undefined && value > field.max) throw new Error(`at most ${field.max}`);
      return value;
    case "select":
      if (typeof value !== "string" || !field.options.some((o) => o.value === value)) {
        throw new Error(`one of: ${field.options.map((o) => o.value).join(", ")}`);
      }
      return value;
    case "duration": {
      if (typeof value !== "string") throw new Error("expected a duration string");
      const ms = parseDuration(value); // throws "invalid duration ..." on bad grammar
      if (field.min !== undefined && ms < parseDuration(field.min)) throw new Error(`at least "${field.min}"`);
      if (field.max !== undefined && ms > parseDuration(field.max)) throw new Error(`at most "${field.max}"`);
      return value;
    }
  }
}
```

```ts
// packages/runtime/src/services/settings.ts
// The settings service (spec 2026-07-07-settings-design.md): the person's knobs.
// Person writes (dashboard/HTTP), apps read+watch their own declared settings,
// services resolve effective values internally. Values live in the Backup tree:
// app settings + per-app overrides in the app's db, platform values in
// data/_platform/settings.sqlite (eventStore's singleton pattern).
import fs from "node:fs";
import path from "node:path";
import type Database from "better-sqlite3";
import BetterSqlite3 from "better-sqlite3";
import { getAppDb } from "../db.js";
import { isValidAppId, scanApps } from "../registry.js";
import type { Config } from "../config.js";
import { parseDuration } from "../duration.js";
import { validateFieldDef, validateValue, APP_KEY_RE, type SettingField } from "../settingsSchema.js";
import { PLATFORM_SETTINGS, PLATFORM_KEY_RE } from "../platformSettings.js";

export const CATALOG_NAME = "settings";

/** Validation/semantic error — mapped to HTTP 400 by the router. */
export class SettingsError extends Error {
  constructor(message?: string) {
    super(message);
    this.name = "SettingsError";
  }
}

// ---------- per-app storage (defs + values) ----------

const ensured = new WeakSet<Database.Database>();

export function getSettingsDb(dataDir: string, appId: string): Database.Database {
  const db = getAppDb(dataDir, appId);
  if (!ensured.has(db)) {
    ensureSchema(db);
    ensured.add(db);
  }
  return db;
}

export function ensureSchema(db: Database.Database): void {
  db.exec(
    `CREATE TABLE IF NOT EXISTS _lodekit_setting_defs (
      key           TEXT PRIMARY KEY,
      field         TEXT,          -- JSON SettingField; NULL when the declaration failed
      error         TEXT,          -- per-field declaration error (spec §5)
      registered_at INTEGER NOT NULL
    );
    CREATE TABLE IF NOT EXISTS _lodekit_setting_values (
      key        TEXT PRIMARY KEY, -- bare = app setting, dotted = service override
      value      TEXT NOT NULL,    -- JSON
      updated_at INTEGER NOT NULL
    );`
  );
}

// Wholesale per successful boot (spec §5): defs absent from the manifest are
// removed and their stored values pruned; a bad field registers with its error
// and never poisons siblings. Dotted (override) values are not the manifest's.
export function applySettingsManifest(db: Database.Database, fields: Record<string, unknown>, now: number): void {
  const txn = db.transaction(() => {
    const keys = new Set<string>();
    for (const [key, raw] of Object.entries(fields)) {
      if (typeof key !== "string" || !APP_KEY_RE.test(key) || key.length > 64) continue;
      keys.add(key);
      let field: SettingField | null = null, error: string | null = null;
      try {
        field = validateFieldDef(key, raw);
      } catch (e) {
        error = e instanceof Error ? e.message : String(e);
      }
      db.prepare(
        `INSERT INTO _lodekit_setting_defs (key, field, error, registered_at)
         VALUES (@key, @field, @error, @now)
         ON CONFLICT(key) DO UPDATE SET field = excluded.field, error = excluded.error, registered_at = excluded.registered_at`
      ).run({ key, field: field ? JSON.stringify(field) : null, error, now });
    }
    const existing = db.prepare("SELECT key FROM _lodekit_setting_defs").all() as { key: string }[];
    for (const { key } of existing) {
      if (keys.has(key)) continue;
      db.prepare("DELETE FROM _lodekit_setting_defs WHERE key = ?").run(key);
      db.prepare("DELETE FROM _lodekit_setting_values WHERE key = ?").run(key);
    }
  });
  txn();
  invalidateSettingsCache();
}

export function listAppDefs(db: Database.Database): { key: string; field: SettingField | null; error: string | null }[] {
  const rows = db.prepare("SELECT key, field, error FROM _lodekit_setting_defs ORDER BY key").all() as
    { key: string; field: string | null; error: string | null }[];
  return rows.map((r) => ({ key: r.key, field: r.field ? (JSON.parse(r.field) as SettingField) : null, error: r.error }));
}

export function getAppDef(db: Database.Database, key: string): { field: SettingField | null; error: string | null } | undefined {
  const r = db.prepare("SELECT field, error FROM _lodekit_setting_defs WHERE key = ?").get(key) as
    { field: string | null; error: string | null } | undefined;
  return r ? { field: r.field ? (JSON.parse(r.field) as SettingField) : null, error: r.error } : undefined;
}

export function getValue(db: Database.Database, key: string): unknown {
  const r = db.prepare("SELECT value FROM _lodekit_setting_values WHERE key = ?").get(key) as { value: string } | undefined;
  return r === undefined ? undefined : (JSON.parse(r.value) as unknown);
}

export function setValue(db: Database.Database, key: string, value: unknown): void {
  db.prepare(
    `INSERT INTO _lodekit_setting_values (key, value, updated_at) VALUES (?, ?, ?)
     ON CONFLICT(key) DO UPDATE SET value = excluded.value, updated_at = excluded.updated_at`
  ).run(key, JSON.stringify(value), Date.now());
  invalidateSettingsCache();
}

export function deleteValue(db: Database.Database, key: string): void {
  db.prepare("DELETE FROM _lodekit_setting_values WHERE key = ?").run(key);
  invalidateSettingsCache();
}

// ---------- platform value store (single-writer singleton, eventStore pattern) ----------

let platformDb: Database.Database | null = null;
let dataDirRef: string | null = null;

// Opens (creating if needed) <dataDir>/_platform/settings.sqlite — the person's
// knobs live in the Backup tree (precious). Degrades to defaults-only when it
// can't open — the runtime must still boot; writes then fail loudly (routes 500).
export function initSettingsStore(dataDir: string): boolean {
  platformDb?.close();
  platformDb = null;
  dataDirRef = dataDir;
  invalidateSettingsCache();
  try {
    const dir = path.join(dataDir, "_platform");
    fs.mkdirSync(dir, { recursive: true });
    platformDb = new BetterSqlite3(path.join(dir, "settings.sqlite"));
    platformDb.pragma("journal_mode = WAL");
    platformDb.exec(
      `CREATE TABLE IF NOT EXISTS settings (
        key        TEXT PRIMARY KEY,
        value      TEXT NOT NULL,
        updated_at INTEGER NOT NULL
      );`
    );
    return true;
  } catch (e) {
    platformDb = null;
    process.stderr.write(`[settings] settings.sqlite unavailable — defaults only: ${e}\n`);
    return false;
  }
}

export function closeSettingsStoreForTest(): void {
  platformDb?.close();
  platformDb = null;
  dataDirRef = null;
  invalidateSettingsCache();
  writeCbs.clear();
}

export function getPlatformValue(key: string): unknown {
  if (!platformDb) return undefined;
  const r = platformDb.prepare("SELECT value FROM settings WHERE key = ?").get(key) as { value: string } | undefined;
  return r === undefined ? undefined : (JSON.parse(r.value) as unknown);
}

export function setPlatformValue(key: string, value: unknown): void {
  if (!platformDb) throw new SettingsError("settings store unavailable");
  platformDb.prepare(
    `INSERT INTO settings (key, value, updated_at) VALUES (?, ?, ?)
     ON CONFLICT(key) DO UPDATE SET value = excluded.value, updated_at = excluded.updated_at`
  ).run(key, JSON.stringify(value), Date.now());
  invalidateSettingsCache();
}

export function deletePlatformValue(key: string): void {
  if (!platformDb) throw new SettingsError("settings store unavailable");
  platformDb.prepare("DELETE FROM settings WHERE key = ?").run(key);
  invalidateSettingsCache();
}

// ---------- effective resolution (spec §7) ----------

// app override → platform value → catalog default; every stored value is
// re-validated on read, so schema drift silently yields the default.
const cache = new Map<string, unknown>();

export function invalidateSettingsCache(): void {
  cache.clear();
}

export function getEffective(key: string, appId?: string): unknown {
  const setting = PLATFORM_SETTINGS[key];
  if (!setting || !PLATFORM_KEY_RE.test(key)) throw new SettingsError(`unknown setting "${key}"`);
  const scopedApp = setting.scope === "per-app" && appId && isValidAppId(appId) ? appId : undefined;
  const cacheKey = `${scopedApp ?? ""} ${key}`;
  if (cache.has(cacheKey)) return cache.get(cacheKey);
  let resolved: unknown = setting.field.default;
  const platform = getPlatformValue(key);
  if (platform !== undefined) {
    try { resolved = validateValue(setting.field, platform); } catch { /* drift → keep default */ }
  }
  if (scopedApp && dataDirRef) {
    const override = getValue(getSettingsDb(dataDirRef, scopedApp), key);
    if (override !== undefined) {
      try { resolved = validateValue(setting.field, override); } catch { /* drift → keep platform/default */ }
    }
  }
  cache.set(cacheKey, resolved);
  return resolved;
}

export const effectiveMs = (key: string, appId?: string): number => parseDuration(getEffective(key, appId) as string);
export const effectiveNumber = (key: string, appId?: string): number => getEffective(key, appId) as number;
export const effectiveString = (key: string, appId?: string): string => getEffective(key, appId) as string;
export const effectiveBoolean = (key: string, appId?: string): boolean => getEffective(key, appId) as boolean;

// ---------- write hook (server.ts re-arms loops; manager/theme ride SSE instead) ----------

const writeCbs = new Set<(key: string, appId?: string) => void>();

export function onSettingsWrite(cb: (key: string, appId?: string) => void): void {
  writeCbs.add(cb);
}

export function notifySettingsWrite(key: string, appId?: string): void {
  for (const cb of writeCbs) cb(key, appId);
}

// Valid explicit per-app overrides of one key across the apps on disk — the
// retention sweeps' input (recoverInterruptedRuns' scan pattern). Global-scope
// keys have no overrides by definition.
export function collectAppOverrides(cfg: Config, key: string): Map<string, unknown> {
  const out = new Map<string, unknown>();
  const setting = PLATFORM_SETTINGS[key];
  if (!setting || setting.scope !== "per-app") return out;
  for (const app of scanApps(cfg.appsDir)) {
    if (!fs.existsSync(path.join(cfg.dataDir, app.appId, "db.sqlite"))) continue;
    const v = getValue(getSettingsDb(cfg.dataDir, app.appId), key);
    if (v === undefined) continue;
    try { out.set(app.appId, validateValue(setting.field, v)); } catch { /* drifted override — skip */ }
  }
  return out;
}
```

```ts
  emitEvent({ ns, source: PLATFORM_NS, type: EVENT, payload: { key }, ttl: CHANGE_FEED_TTL_S });

  if (stored === undefined || stored === null) return false;
  try { validateValue(field, stored); return false; } catch { return true; }

function readDeclared(db: Database.Database, key: string): { found: boolean; value?: unknown } {
  const def = getAppDef(db, key);
  if (!def || !def.field) return { found: false };
  const stored = getValue(db, key);
  if (stored !== undefined) {
    try { return { found: true, value: validateValue(def.field, stored) }; } catch { /* drift */ }
  }
  return { found: true, value: def.field.default };

export const settingsRoutes = new Hono<SettingsEnv>()
  .onError((err, c) => c.json({ error: err instanceof Error ? err.message : String(err) }, 400))
  .get("/", (c) => {
    const db = c.var.settingsDb;
    const declared = listAppDefs(db).map((d) => {
      const value = getValue(db, d.key) ?? null;
      return {
        key: d.key,
        field: d.field,
        error: d.error,
        value,
        effective: d.field ? readDeclared(db, d.key).value : null,
        drifted: d.field ? isDrifted(d.field, value) : false,
      };
    });
    const overrides = Object.entries(PLATFORM_SETTINGS)
      .filter(([, s]) => s.scope === "per-app")
      .map(([key, s]) => ({
        key,
        section: s.section,
        advanced: s.field.advanced ?? false,
        field: s.field,
        platformEffective: getEffective(key),
        override: getValue(db, key) ?? null,
      }));

  })

    return c.json(readDeclared(c.var.settingsDb, c.req.valid("param").key));
  })
  .put("/:key", zValidator("param", keyParam, validationHook), zValidator("json", valueBody, validationHook), (c) => {
    const { key } = c.req.valid("param");
    const raw = c.req.valid("json").value;
    const field = fieldForAppWrite(c.var.settingsDb, key);
    let value;
    try {
      value = validateValue(field, raw);
    } catch (e) {
      throw new SettingsError(`${key}: ${e instanceof Error ? e.message : String(e)}`);
    }
    setValue(c.var.settingsDb, key, value);
    notifySettingsWrite(key, c.var.appId);
    emitSettingsChange(c.var.appId, key);
    return c.json({ ok: true as const });
  })
  .delete("/:key", zValidator("param", keyParam, validationHook), (c) => {
    const { key } = c.req.valid("param");
    fieldForAppWrite(c.var.settingsDb, key); // 400 on unknown/global — deletes are gated like writes
    deleteValue(c.var.settingsDb, key);
    notifySettingsWrite(key, c.var.appId);
    emitSettingsChange(c.var.appId, key);
    return c.json({ ok: true as const });
  });

// Bare key → the app's declared field; dotted key → a per-app platform setting.
function fieldForAppWrite(db: Database.Database, key: string): SettingField {
  if (key.includes(".")) {
    const s = PLATFORM_SETTINGS[key];
    if (!s) throw new SettingsError(`unknown setting "${key}"`);
    if (s.scope !== "per-app") throw new SettingsError(`"${key}" applies to all apps and cannot be overridden`);
    return s.field;
  }
  const def = getAppDef(db, key);
  if (!def) throw new SettingsError(`unknown setting "${key}"`);
  if (!def.field) throw new SettingsError(`"${key}" has a declaration error: ${def.error}`);
  return def.field;
}
```

```ts
// The declaration side of the settings service (spec §5): builders + a thin
// validator/tagger, PLUS the typed read facade. appWorkerEntry scans the built
// src/settings.ts DEFAULT export for the __lodekitSettings marker and posts
// `fields` as the settings manifest; full validation is runtime-side.
// The facade methods delegate to the SDK singleton's `settings` handle
// (bound by index.ts at module init), so one import gives typed reads:
//   import settings from "./settings";  →  await settings.get("layout")
import type { Settings } from "./client.js";

interface FieldBase { label: string; description: string; advanced?: boolean }
export interface BooleanSetting extends FieldBase { type: "boolean"; default: boolean }
export interface StringSetting extends FieldBase { type: "string"; default: string; maxLength?: number; placeholder?: string }
export interface NumberSetting extends FieldBase { type: "number"; default: number; min?: number; max?: number; step?: number; integer?: boolean }
export interface SelectOption { readonly value: string; readonly label: string }
export interface SelectSetting<O extends readonly SelectOption[] = readonly SelectOption[]> extends FieldBase {
  type: "select"; options: O; default: O[number]["value"];
}
export interface DurationSetting extends FieldBase { type: "duration"; default: string; min?: string; max?: string }
export type AnySetting = BooleanSetting | StringSetting | NumberSetting | SelectSetting | DurationSetting;

export const boolean = (cfg: Omit<BooleanSetting, "type">): BooleanSetting => ({ type: "boolean", ...cfg });
export const string = (cfg: Omit<StringSetting, "type">): StringSetting => ({ type: "string", ...cfg });
export const number = (cfg: Omit<NumberSetting, "type">): NumberSetting => ({ type: "number", ...cfg });
export const duration = (cfg: Omit<DurationSetting, "type">): DurationSetting => ({ type: "duration", ...cfg });
export function select<const O extends readonly SelectOption[]>(
  cfg: Omit<SelectSetting<O>, "type">
): SelectSetting<O> {
  return { type: "select", ...cfg };
}

export type SettingValue<F> =
  F extends BooleanSetting ? boolean
  : F extends NumberSetting ? number
  : F extends SelectSetting<infer O> ? O[number]["value"]
  : string;

export type SettingsFields = Record<string, AnySetting>;

export interface DefinedSettings<S extends SettingsFields> {
  __lodekitSettings: true;
  fields: S;
  get<K extends keyof S & string>(key: K): Promise<SettingValue<S[K]> | undefined>;
  all(): Promise<{ [K in keyof S]: SettingValue<S[K]> }>;
  watch(cb: (change: { key: keyof S & string }) => void): () => void;
}

const KEY_RE = /^[a-z0-9_]+$/;

let bound: Settings | null = null;
/** @internal wired by index.ts to the SDK singleton */
export function _bindSettings(s: Settings): void { bound = s; }
function handle(): Settings {
  if (!bound) throw new Error("settings unavailable (no bound client — outside an app build?)");
  return bound;
}

export function defineSettings<S extends SettingsFields>(fields: S): DefinedSettings<S> {
  for (const [key, f] of Object.entries(fields)) {
    if (!KEY_RE.test(key) || key.length > 64) throw new Error(`defineSettings(): invalid key "${key}" (snake_case, max 64)`);
    if (typeof f?.label !== "string" || !f.label) throw new Error(`defineSettings(): "${key}" needs a label`);
    if (typeof f?.description !== "string" || !f.description) throw new Error(`defineSettings(): "${key}" needs a description`);
    if (!("default" in f)) throw new Error(`defineSettings(): "${key}" needs a default`);
  }
  return {
    __lodekitSettings: true,
    fields,
    get: (key) => handle().get(key) as never,
    all: () => handle().all() as never,
    watch: (cb) => handle().watch(cb as (c: { key: string }) => void),
  };
}
```

```ts
export function sweepLogStore(opts: { maxAgeMs?: number; maxRows?: number; appAges?: Map<string, number> } = {}): number {
  if (!db) return 0;
  const maxAgeMs = opts.maxAgeMs ?? RETENTION_MAX_AGE_MS;
  const maxRows = opts.maxRows ?? RETENTION_MAX_ROWS;
  const appAges = opts.appAges ?? new Map<string, number>();
  try {
    // Per-app override ages first, then the global age for everyone else
    // (app_id IS NULL — the platform — always uses the global age).
    let deleted = 0;
    for (const [appId, ageMs] of appAges) {
      deleted += db.prepare("DELETE FROM logs WHERE app_id = ? AND ts < ?").run(appId, Date.now() - ageMs).changes;
    }
    const skip = [...appAges.keys()];
    deleted += db
      .prepare(`DELETE FROM logs WHERE ts < ? AND (app_id IS NULL OR app_id NOT IN (${skip.map(() => "?").join(",") || "''"}))`)
      .run(Date.now() - maxAgeMs, ...skip).changes;
    deleted += db
      .prepare("DELETE FROM logs WHERE id <= (SELECT id FROM logs ORDER BY id DESC LIMIT 1 OFFSET ?)")
      .run(maxRows).changes;
    return deleted;
  } catch (e) {
    process.stderr.write(`[logger] log sweep failed: ${e}\n`);
    return 0;
  }
}
```

```js
"use strict";
const http = require("node:http");

// Applies runtime-owned platform settings to the OS/tray (settings spec §9).
// The runtime is the store; this module is the applier. All effects are
// injected (supervisor.js pattern) so tests run without Electron or HTTP.
//
// Reconcile rule: on start, the OS login item is the applied truth — a mismatch
// writes the OS state back to the setting. After that, settings-change events
// (person edits in the dashboard) apply to the OS/tray.

function createRuntimeSettings(deps) {
  const {
    port, log, onIconStyle, getLoginItem, setLoginItem, canSetLogin,
    putSetting = defaultPutSetting, fetchSettings = defaultFetchSettings,
    subscribe = defaultSubscribe, cacheIconStyle,
  } = deps;
  let unsubscribe = null;

  function effective(doc, key) {
    const s = (doc.settings || []).find((x) => x.key === key);
    return s ? s.effective : undefined;
  }

  async function applyDoc(doc, { reconcileLogin }) {
    const icon = effective(doc, "appearance.icon_style");
    if (icon) {
      onIconStyle(icon);
      cacheIconStyle(icon);
    }
    if (!canSetLogin) return;
    const desired = effective(doc, "general.start_at_login");
    if (typeof desired !== "boolean") return;
    const actual = getLoginItem();
    if (actual === desired) return;
    if (reconcileLogin) await putSetting("general.start_at_login", actual); // OS wins on connect
    else setLoginItem(desired); // dashboard wins after connect
  }

  return {
    async start() {
      const doc = await fetchSettings();
      await applyDoc(doc, { reconcileLogin: true });
      unsubscribe = subscribe(async (key) => {
        if (key !== "appearance.icon_style" && key !== "general.start_at_login") return;
        try {
          await applyDoc(await fetchSettings(), { reconcileLogin: false });
        } catch (e) {
          log(`runtimeSettings: ${e.message}`);
        }
      });
    },
    stop() {
      if (unsubscribe) unsubscribe();
      unsubscribe = null;
    },
  };

  // ---- production defaults (node:http against the local runtime) ----

  function defaultFetchSettings() {
    return new Promise((resolve, reject) => {
      http.get({ host: "127.0.0.1", port, path: "/api/settings" }, (res) => {
        let body = "";
        res.on("data", (c) => (body += c));
        res.on("end", () => {
          try { resolve(JSON.parse(body)); } catch (e) { reject(e); }
        });
      }).on("error", reject);
    });
  }

  function defaultPutSetting(key, value) {
    return new Promise((resolve, reject) => {
      const req = http.request(
        { host: "127.0.0.1", port, path: `/api/settings/${key}`, method: "PUT", headers: { "Content-Type": "application/json" } },
        (res) => { res.resume(); res.statusCode === 200 ? resolve() : reject(new Error(`PUT ${key}: ${res.statusCode}`)); }
      );
      req.on("error", reject);
      req.end(JSON.stringify({ value }));
    });
  }

  // Minimal SSE consumer over node:http: platform settings-change events ride
  // the bus envelope (wire name "event", ns "_platform", type "settings-change").
  function defaultSubscribe(onChange) {
    const req = http.get({ host: "127.0.0.1", port, path: "/api/events" }, (res) => {
      let buf = "";
      res.on("data", (chunk) => {
        buf += chunk;
        let idx;
        while ((idx = buf.indexOf("\n\n")) !== -1) {
          const frame = buf.slice(0, idx);
          buf = buf.slice(idx + 2);
          const isEvent = /^event: event$/m.test(frame);
          const data = frame.split("\n").find((l) => l.startsWith("data: "));
          if (!isEvent || !data) continue;
          try {
            const d = JSON.parse(data.slice(6));
            if (d.type === "settings-change" && d.ns === "_platform" && d.payload) onChange(d.payload.key);
          } catch { /* partial or non-JSON frame — skip */ }
        }
      });
    });
    req.on("error", (e) => log(`runtimeSettings SSE: ${e.message}`));
    return () => req.destroy();
  }
}

module.exports = { createRuntimeSettings };
```
