# Hero Animated Prompt-UI Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Each Task becomes a bead (`bd create -t task --parent <epic-id>`). Steps within tasks use checkbox (`- [ ]`) syntax for human readability.

**Goal:** Replace the hero jar illustration with a scripted, play-once animated chat demo (vendored prompt-kit) showing a person building the Greenhouse app with Lodekit, per `docs/specs/2026-07-19-hero-demo-design.md`.

**Architecture:** A single React island (`HeroDemo`) in the Astro landing site. `script.ts` holds the storyboard as data with a pure reducer (`applyBeat`) and duration function; `timeline.ts` is a pausable sequential runner over beats; vendored, trimmed prompt-kit components render the conversation in the print identity. SSR emits the final frame; on mount (motion allowed) the island resets and plays once, then rests. Replay = the `/clear` beat.

**Tech Stack:** Astro 7 + React 19 island, Tailwind v4 tokens (already themed), vitest (workspace convention), vendored prompt-kit (MIT, upstream commit `de80375967400aa0c6ebab9d3ba4f9258ab79fcc`). No new runtime npm dependencies.

// The hero demo storyboard — single source of truth for the scripted
// conversation (docs/specs/2026-07-19-hero-demo-design.md §2).
// Beats are declarative targets; components animate toward them, and
// beatDuration budgets the time each beat's animation needs.

// Both ≥ 2 rAF frames (33.4ms) so the timeline's duration budget always
// covers the visual typewriter — otherwise streams snap at beat end.
export const TYPE_MS = 45; // input typewriter, ms per character
export const STREAM_MS = 35; // agent message stream, ms per character

export type DemoOption = { label: string; detail: string };

export type DemoItem =
  | { kind: "user"; text: string }
  | { kind: "agent"; text: string }
  | { kind: "options"; options: DemoOption[]; pressed: number | null }
  | { kind: "reasoning"; label: string; active: boolean }
  | { kind: "tool"; via: "mcp" | "file"; name: string; caption: string; done: boolean };

export type DemoState = {
  items: DemoItem[];
  input: string;
  streamingIndex: number | null; // items index currently typewriting (agent msg)
};

export type Beat =
  | { do: "type"; text: string } // typewriter into the prompt input
  | { do: "post"; item: DemoItem } // append item; a user post clears the input
  | { do: "press"; option: number } // scripted press on the options row
  | { do: "toolDone" } // oldest running tool row completes
  | { do: "settle" } // reasoning row goes inactive
  | { do: "clear" } // conversation empties (replay)
  | { do: "hold"; ms: number };

export const EMPTY: DemoState = { items: [], input: "", streamingIndex: null };

const ASK = "Build me something to manage my greenhouse based on my local weather forecast.";

const OPTIONS: DemoOption[] = [
  { label: "Single file", detail: "works until it needs to remember anything. No storage, no schedule." },
  { label: "Cloud app", detail: "an account, a subscription, your data on someone else's computer." },
  { label: "Lodekit", detail: "runs on your Mac. Real database, scheduled tasks, yours forever." },
];

export const SCRIPT: Beat[] = [
  { do: "hold", ms: 600 },
  { do: "type", text: ASK },
  { do: "hold", ms: 500 },
  { do: "post", item: { kind: "user", text: ASK } },
  { do: "hold", ms: 900 },
  { do: "post", item: { kind: "agent", text: "I can build that a few ways:" } },
  { do: "post", item: { kind: "options", options: OPTIONS, pressed: null } },
  { do: "hold", ms: 6000 },
  { do: "press", option: 2 },
  { do: "hold", ms: 500 },
  { do: "post", item: { kind: "user", text: "Lodekit." } },
  { do: "hold", ms: 1100 },
  { do: "post", item: { kind: "reasoning", label: "Using skill: Building with Lodekit", active: true } },
  { do: "hold", ms: 2600 },
  { do: "settle" },
  { do: "post", item: { kind: "tool", via: "mcp", name: "lodekit_scaffold", caption: 'Scaffolding new Lodekit app "greenhouse"', done: false } },
  { do: "hold", ms: 2200 },
  { do: "toolDone" },
  { do: "hold", ms: 600 },
  { do: "post", item: { kind: "tool", via: "file", name: "greenhouse/src/db.ts", caption: "Creating the greenhouse database", done: false } },
  { do: "hold", ms: 2000 },
  { do: "toolDone" },
  { do: "hold", ms: 600 },
  { do: "post", item: { kind: "tool", via: "file", name: "greenhouse/src/gateways.ts", caption: "Connecting a gateway to the weather forecast", done: false } },
  { do: "hold", ms: 2000 },
  { do: "toolDone" },
  { do: "hold", ms: 900 },
  { do: "post", item: { kind: "agent", text: "Your app is ready at http://lodekit.localhost/greenhouse — it checks the forecast every morning and takes it from there." } },
];

export const CLEAR_SCRIPT: Beat[] = [
  { do: "type", text: "/clear" },
  { do: "hold", ms: 400 },
  { do: "clear" },
  { do: "hold", ms: 700 },
];

export function applyBeat(state: DemoState, beat: Beat): DemoState {
  switch (beat.do) {
    case "hold":
      return state;
    case "type":
      return { ...state, input: beat.text };
    case "post": {
      const items = [...state.items, beat.item];
      return {
        items,
        input: beat.item.kind === "user" ? "" : state.input,
        streamingIndex: beat.item.kind === "agent" ? items.length - 1 : null,
      };
    }
    case "press":
      return {
        ...state,
        items: state.items.map((it) =>
          it.kind === "options" ? { ...it, pressed: beat.option } : it
        ),
      };
    case "toolDone": {
      const i = state.items.findIndex((it) => it.kind === "tool" && !it.done);
      if (i === -1) return state;
      const items = [...state.items];
      const it = items[i];
      if (it.kind === "tool") items[i] = { ...it, done: true };
      return { ...state, items };
    }
    case "settle":
      return {
        ...state,
        items: state.items.map((it) =>
          it.kind === "reasoning" ? { ...it, active: false } : it
        ),
      };
    case "clear":
      return EMPTY;
  }
}

export function beatDuration(beat: Beat): number {
  switch (beat.do) {
    case "hold":
      return beat.ms;
    case "type":
      return beat.text.length * TYPE_MS;
    case "post":
      return beat.item.kind === "agent"
        ? beat.item.text.length * STREAM_MS + 450
        : 450;
    case "press":
      return 350;
    case "toolDone":
      return 350;
    case "settle":
      return 300;
    case "clear":
      return 500;
  }
}

export function restState(): DemoState {
  return { ...SCRIPT.reduce(applyBeat, EMPTY), streamingIndex: null };
}
```

// Pausable sequential runner for the demo script (spec §3). Each beat is
// applied immediately, then the runner waits beatDuration before the next —
// components animate within that budget, so the runner stays deterministic.
import { applyBeat, beatDuration, type Beat, type DemoState } from "./script";

export type Timeline = {
  play: (beats: Beat[], from: DemoState) => void;
  pause: () => void;
  resume: () => void;
  stop: () => void;
  playing: () => boolean;
};

export function createTimeline(
  onChange: (s: DemoState) => void,
  onDone: (s: DemoState) => void
): Timeline {
  let queue: Beat[] = [];
  let state: DemoState = { items: [], input: "", streamingIndex: null };
  let timer: ReturnType<typeof setTimeout> | null = null;
  let startedAt = 0;
  let remaining = 0;
  let paused = false;

  function wait(ms: number) {
    startedAt = Date.now();
    remaining = ms;
    timer = setTimeout(() => {
      timer = null;
      next();
    }, ms);
  }

  function next() {
    const beat = queue.shift();
    if (!beat) {
      onDone(state);
      return;
    }
    state = applyBeat(state, beat);
    onChange(state);
    wait(beatDuration(beat));
  }

  return {
    play(beats, from) {
      this.stop();
      queue = [...beats];
      state = from;
      paused = false;
      next();
    },
    pause() {
      if (paused || !timer) return;
      clearTimeout(timer);
      timer = null;
      remaining -= Date.now() - startedAt;
      paused = true;
    },
    resume() {
      if (!paused) return;
      paused = false;
      wait(Math.max(0, remaining));
    },
    stop() {
      if (timer) clearTimeout(timer);
      timer = null;
      queue = [];
      paused = false;
    },
    playing: () => timer !== null,
  };
}
```

// Vendored from prompt-kit (MIT) — https://github.com/ibelick/prompt-kit
// @ de80375, trimmed for the scripted hero demo: typewriter mode only,
// string input only (no fade mode, no async iterables, no Intl.Segmenter).
import { useCallback, useEffect, useRef, useState } from "react";

export type UseTextStreamOptions = {
  textStream: string;
  segmentDelay?: number; // ms per character
  onComplete?: () => void;
};

export function useTextStream({
  textStream,
  segmentDelay = 25,
  onComplete,
}: UseTextStreamOptions) {
  const [displayedText, setDisplayedText] = useState("");
  const [isComplete, setIsComplete] = useState(false);
  const indexRef = useRef(0);
  const frameRef = useRef<number | null>(null);
  const onCompleteRef = useRef(onComplete);

  useEffect(() => {
    onCompleteRef.current = onComplete;
  }, [onComplete]);

  const start = useCallback(() => {
    indexRef.current = 0;
    setDisplayedText("");
    setIsComplete(false);
    let lastFrame = 0;

    const step = (timestamp: number) => {
      if (segmentDelay > 0 && timestamp - lastFrame < segmentDelay) {
        frameRef.current = requestAnimationFrame(step);
        return;
      }
      lastFrame = timestamp;
      indexRef.current += 1;
      setDisplayedText(textStream.slice(0, indexRef.current));
      if (indexRef.current < textStream.length) {
        frameRef.current = requestAnimationFrame(step);
      } else {
        setIsComplete(true);
        onCompleteRef.current?.();
      }
    };

    if (textStream.length === 0) {
      setIsComplete(true);
      return;
    }
    frameRef.current = requestAnimationFrame(step);
  }, [textStream, segmentDelay]);

  useEffect(() => {
    start();
    return () => {
      if (frameRef.current !== null) cancelAnimationFrame(frameRef.current);
    };
  }, [start]);

  return { displayedText, isComplete };
}

export function ResponseStream({
  textStream,
  segmentDelay = 25,
  className,
  as: Container = "div",
}: {
  textStream: string;
  segmentDelay?: number;
  className?: string;
  as?: keyof React.JSX.IntrinsicElements;
}) {
  const { displayedText } = useTextStream({ textStream, segmentDelay });
  return <Container className={className}>{displayedText}</Container>;
}

// The hero demo island (docs/specs/2026-07-19-hero-demo-design.md).
// SSR renders the completed conversation; with motion allowed the island
// resets after the hero entrance, plays the script once, then rests.
import { useEffect, useRef, useState } from "react";
import { RotateCcw } from "lucide-react";
import { cn } from "@/lib/utils";
import {
  CLEAR_SCRIPT,
  EMPTY,
  restState,
  SCRIPT,
  STREAM_MS,
  TYPE_MS,
  type DemoItem,
  type DemoState,
} from "./script";
import { createTimeline, type Timeline } from "./timeline";
import { Message, MessageContent } from "./prompt-kit/message";
import { PromptInput, PromptInputActions, PromptInputDisplay } from "./prompt-kit/prompt-input";
import { ToolRow } from "./prompt-kit/tool";
import { ReasoningRow } from "./prompt-kit/reasoning";
import { useTextStream } from "./prompt-kit/response-stream";
import { PromptSuggestion } from "./prompt-kit/prompt-suggestion";

const ENTRANCE_DELAY_MS = 900; // hero entrance (≤800ms) + settle

function DemoConversationItem({
  item,
  streamText,
}: {
  item: DemoItem;
  streamText?: string; // set only while this agent message is typewriting
}) {
  switch (item.kind) {
    case "user":
      return (
        <Message role="user">
          <MessageContent role="user">{item.text}</MessageContent>
        </Message>
      );
    case "agent":
      return (
        <Message role="agent">
          <MessageContent role="agent">
            {streamText !== undefined ? streamText : <AgentText text={item.text} />}
          </MessageContent>
        </Message>
      );
    case "options":
      return (
        <div className="flex flex-col gap-1.5 pl-0.5">
          {item.options.map((o, i) => (
            <PromptSuggestion key={o.label} label={o.label} detail={o.detail} pressed={item.pressed === i} />
          ))}
        </div>
      );
    case "reasoning":
      return <ReasoningRow label={item.label} active={item.active} />;
    case "tool":
      return <ToolRow via={item.via} name={item.name} caption={item.caption} done={item.done} />;
  }
}

// Renders the final message with its URL styled as a link (visual only —
// the demo is a movie; a real anchor would invite a dead-end click).
function AgentText({ text }: { text: string }) {
  const url = "http://lodekit.localhost/greenhouse";
  const at = text.indexOf(url);
  if (at === -1) return <>{text}</>;
  return (
    <>
      {text.slice(0, at)}
      <span className="font-mono text-[0.8125rem] text-primary underline underline-offset-2">{url}</span>
      {text.slice(at + url.length)}
    </>
  );
}

const REST = restState();

function Transcript() {
  return (
    <div className="sr-only">
      <p>A conversation with an agent:</p>
      <ul>
        {REST.items.map((item, i) => (
          <li key={i}>
            {item.kind === "user" && `You: ${item.text}`}
            {item.kind === "agent" && `Agent: ${item.text}`}
            {item.kind === "options" &&
              `Options: ${item.options.map((o) => `${o.label} — ${o.detail}`).join(" / ")}`}
            {item.kind === "reasoning" && item.label}
            {item.kind === "tool" && `${item.name}: ${item.caption}`}
          </li>
        ))}
      </ul>
    </div>
  );
}

export default function HeroDemo() {
  const [state, setState] = useState<DemoState>(REST);
  const [resting, setResting] = useState(true);
  const [reduced, setReduced] = useState(false);
  const timelineRef = useRef<Timeline | null>(null);
  const scrollRef = useRef<HTMLDivElement | null>(null);
  const cardRef = useRef<HTMLDivElement | null>(null);
  const cycleRef = useRef(0);
  const prevLenRef = useRef(REST.items.length);

  const { displayedText } = useTextStream({
    textStream: state.input,
    segmentDelay: TYPE_MS,
  });

  const streamingItem =
    state.streamingIndex !== null ? state.items[state.streamingIndex] : null;
  const { displayedText: streamedAgentText } = useTextStream({
    textStream: streamingItem?.kind === "agent" ? streamingItem.text : "",
    segmentDelay: STREAM_MS,
  });

  useEffect(() => {
    if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) {
      setReduced(true);
      return;
    }
    const tl = createTimeline(
      (s) => {
        if (s.items.length < prevLenRef.current) cycleRef.current += 1;
        prevLenRef.current = s.items.length;
        setState(s);
      },
      (s) => {
        setState({ ...s, streamingIndex: null });
        setResting(true);
      }
    );
    timelineRef.current = tl;
    const start = setTimeout(() => {
      setResting(false);
      prevLenRef.current = 0;
      cycleRef.current += 1;
      setState(EMPTY);
      tl.play(SCRIPT, EMPTY);
    }, ENTRANCE_DELAY_MS);

    const io = new IntersectionObserver(
      ([entry]) => {
        if (entry.isIntersecting) tl.resume();
        else tl.pause();
      },
      { threshold: 0.2 }
    );
    if (cardRef.current) io.observe(cardRef.current);

    return () => {
      clearTimeout(start);
      io.disconnect();
      tl.stop();
    };
  }, []);

  useEffect(() => {
    scrollRef.current?.scrollTo({
      top: scrollRef.current.scrollHeight,
      behavior: "smooth",
    });
  }, [state.items.length]);

  // keep the growing streamed message in view without restarting the
  // smooth scroll animation on every character
  useEffect(() => {
    scrollRef.current?.scrollTo({ top: scrollRef.current.scrollHeight });
  }, [streamedAgentText]);

  const replay = () => {
    const tl = timelineRef.current;
    if (!tl || reduced) return;
    setResting(false);
    tl.play([...CLEAR_SCRIPT, ...SCRIPT], state);
  };

  return (
    <div
      ref={cardRef}
      className="flex h-[540px] flex-col overflow-hidden rounded-lg border border-border bg-card"
    >
      <div className="flex items-center justify-between border-b border-border px-4 py-2.5">
        <span className="kicker text-muted-foreground">Agent session — greenhouse</span>
        {resting && !reduced && (
          <button
            type="button"
            onClick={replay}
            aria-label="Replay demo"
            className="chip inline-flex cursor-pointer items-center gap-1.5 transition-opacity duration-200 hover:opacity-70 focus-visible:outline-2 focus-visible:outline-solid focus-visible:outline-offset-[3px] focus-visible:outline-ring"
            style={{ transitionTimingFunction: "var(--ease-drift)" }}
          >
            <RotateCcw className="size-3" />
            Replay
          </button>
        )}
      </div>
      <div aria-hidden="true" className="pointer-events-none flex min-h-0 flex-1 flex-col select-none">
        <div ref={scrollRef} className="flex min-h-0 flex-1 flex-col gap-3.5 overflow-y-auto p-4">
          {state.items.map((item, i) => (
            <div key={`${cycleRef.current}:${i}`} className="demo-item">
              <DemoConversationItem
                item={item}
                streamText={i === state.streamingIndex ? streamedAgentText : undefined}
              />
            </div>
          ))}
        </div>
        <div className="border-t border-border p-3">
          <PromptInput>
            <PromptInputDisplay text={displayedText} />
            <PromptInputActions />
          </PromptInput>
        </div>
      </div>
      <Transcript />
    </div>
  );
}

## Notes

- **Deviations from spec §3, restated:** no `ui/textarea.tsx` (display-only input div), no vendored `loader.tsx` (shared `demo-pulse` covers running state), no `chat-container` (a plain scrolling div + scripted `scrollTo`). All trims remove files with no consumer; the vendored set is 6 files, not 8.
- **Timing note:** the timeline budgets stream time from text length (`beatDuration`), so component typewriters and the runner stay in sync without callbacks. `TYPE_MS`/`STREAM_MS` are ≥ 2 rAF frames (33.4ms) so the visual typewriter never outruns its budget (frame quantization). If a stream is paused off-screen mid-beat its text may complete early (rAF pauses in background tabs but not on scroll-away); the drift is bounded to a single beat and invisible off-screen — accepted simplification.
- **Streaming lives in `HeroDemo`, not per-item:** both typewriters (input + agent message) run through `useTextStream` at the island root, so the scroll effect can track the growing text. The vendored `ResponseStream` wrapper ships for completeness but the island consumes the hook directly.
- **Pacing envelope:** Σ durations ≈ 33s + entrance delay, inside the spec's ~35–40s reading. Tune `hold` values at manual verify if beats feel rushed; the script.test envelope (25–45s) is the guardrail.
