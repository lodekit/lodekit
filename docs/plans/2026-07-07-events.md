# Events Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the unified event bus — the event-store service, internal namespaces, and the migration of every platform emitter and consumer onto it — per `docs/specs/2026-07-07-events-design.md`.

**Architecture:** A durable append-only event log (`data/_platform/events.sqlite`, monotonic row id = offset) fed by a single `emitEvent` facade that persists then broadcasts over the existing `sse.ts` transport. One SSE wire name (`event: event`) carries the stored envelope; the `log` tail keeps its own `log` wire name. Build/lifecycle/registry broadcasts and the kv/file change feeds migrate onto the facade; `kv.watch`/`files.watch` are replaced by the SDK's `events` handle; the dashboard gains an Events view and MCP a `lodekit_events` tool. The `platform` log sentinel renames to `_platform` under the internal-namespace convention.

**Tech Stack:** Node + Hono + better-sqlite3 + zod (runtime, buildless via tsx); Hono `hc` RPC (SDK); TanStack Start + @lodekit/ui (dashboard); @modelcontextprotocol/sdk (MCP); vitest.

## Global Constraints

- All installs/commands run from the repo root; **never** `pnpm install` with CWD inside `manager/` (CLAUDE.md gotcha).
- Runtime and SDK are buildless — no build step, no new dependencies anywhere in this slice.
- Grammar: `ns`/`source` match `^_?[a-z0-9-]+$`; `type` matches `^[a-z0-9-]+$` (max 128 chars).
- Payload: JSON object, ≤ 8192 bytes serialized. `ttl`: positive integer seconds, ≤ 2 592 000 (30 days).
- Retention constants: 30 days max age, 50 000 rows cap. Change-feed events carry `ttl` 604 800 (7 days).
- Store path: `<dataDir>/_platform/events.sqlite`, WAL, single writer (the host process).
- Wire shape: SSE `event: event`, `data:` = envelope `{id, ts, ns, source, type, payload}`. The `log` tail stays `event: log`. `sse.ts` itself is not modified.
- `emitEvent` never throws; insert failure still broadcasts (envelope `id: 0`) — history gap, never delivery gap.
- Internal namespaces: `_platform`, `_manager`, `_dashboard`. No reserved-word checks anywhere — the app-id grammar (no underscore) is the enforcement.
- Commits: `type(scope): message` style, **no Co-Authored-By trailers**. Commit directly on the current `stack` branch.
- Run a single test file with: `pnpm --filter @lodekit/runtime exec vitest run tests/<file>` (SDK: `pnpm --filter @lodekit/sdk exec vitest run tests/<file>`).

`packages/runtime/src/eventStore.ts` (mirrors `logStore.ts` — same singleton/degradation pattern):

```ts
import fs from "node:fs";
import path from "node:path";
import Database from "better-sqlite3";

export interface EventRecord {
  id: number;
  ts: number;
  ns: string;
  source: string;
  type: string;
  payload: Record<string, unknown> | null;
}

export interface EventWrite {
  ns: string;
  source: string;
  type: string;
  payload?: Record<string, unknown> | null;
  ttl?: number; // seconds
}

export interface EventQuery {
  ns?: string;
  type?: string;
  after?: number; // ascending replay: id > after
  before?: number; // newest-first pagination: id < before
  limit?: number;
}

const RETENTION_MAX_AGE_MS = 30 * 24 * 60 * 60 * 1000;
const RETENTION_MAX_ROWS = 50_000;

// Single-writer singleton: every event flows through the host process (spec §4).
let db: Database.Database | null = null;

// Opens (creating if needed) <dataDir>/_platform/events.sqlite — the bus lives in the
// platform's internal namespace inside the Backup tree (precious; spec §1/§3). Returns
// false and degrades to broadcast-only when it can't open — the runtime must still boot.
export function initEventStore(dataDir: string): boolean {
  db?.close();
  db = null;
  try {
    const dir = path.join(dataDir, "_platform");
    fs.mkdirSync(dir, { recursive: true });
    db = new Database(path.join(dir, "events.sqlite"));
    db.pragma("journal_mode = WAL");
    db.exec(
      `CREATE TABLE IF NOT EXISTS events (
        id         INTEGER PRIMARY KEY,
        ts         INTEGER NOT NULL,
        ns         TEXT NOT NULL,
        source     TEXT NOT NULL,
        type       TEXT NOT NULL,
        payload    TEXT,
        expires_at INTEGER
      );
      CREATE INDEX IF NOT EXISTS events_ns ON events(ns, id);
      CREATE INDEX IF NOT EXISTS events_ts ON events(ts);`
    );
    return true;
  } catch (e) {
    db = null;
    process.stderr.write(`[events] events.sqlite unavailable — live-only event bus: ${e}\n`);
    return false;
  }
}

interface Row { id: number; ts: number; ns: string; source: string; type: string; payload: string | null }

const toRecord = (r: Row): EventRecord => ({
  id: r.id,
  ts: r.ts,
  ns: r.ns,
  source: r.source,
  type: r.type,
  payload: r.payload ? (JSON.parse(r.payload) as Record<string, unknown>) : null,
});

export function insertEvent(w: EventWrite): EventRecord | null {
  if (!db) return null;
  try {
    const ts = Date.now();
    const info = db
      .prepare("INSERT INTO events (ts, ns, source, type, payload, expires_at) VALUES (?, ?, ?, ?, ?, ?)")
      .run(ts, w.ns, w.source, w.type, w.payload ? JSON.stringify(w.payload) : null, w.ttl ? ts + w.ttl * 1000 : null);
    return { id: Number(info.lastInsertRowid), ts, ns: w.ns, source: w.source, type: w.type, payload: w.payload ?? null };
  } catch (e) {
    process.stderr.write(`[events] event write failed: ${e}\n`);
    return null;
  }
}

// `after` reads oldest-first from an offset (replay); otherwise newest-first with
// `before` as the pagination cursor. `next` continues whichever mode ran (null = no more).
// Expired-but-unswept rows are excluded at read time (kv-style lazy expiry, spec §6).
export function queryEvents(opts: EventQuery = {}): { records: EventRecord[]; next: number | null } {
  if (!db) return { records: [], next: null };
  const limit = Math.min(Math.max(1, Math.floor(opts.limit ?? 100)), 1000);
  const asc = opts.after != null;
  const where: string[] = ["(expires_at IS NULL OR expires_at > ?)"];
  const params: unknown[] = [Date.now()];
  if (opts.ns) { where.push("ns = ?"); params.push(opts.ns); }
  if (opts.type) { where.push("type = ?"); params.push(opts.type); }
  if (asc) { where.push("id > ?"); params.push(opts.after); }
  else if (opts.before != null) { where.push("id < ?"); params.push(opts.before); }
  try {
    const rows = db
      .prepare(
        `SELECT id, ts, ns, source, type, payload FROM events
         WHERE ${where.join(" AND ")}
         ORDER BY id ${asc ? "ASC" : "DESC"} LIMIT ?`
      )
      .all(...params, limit) as Row[];
    const records = rows.map(toRecord);
    return { records, next: rows.length === limit ? records[records.length - 1].id : null };
  } catch (e) {
    process.stderr.write(`[events] event query failed: ${e}\n`);
    return { records: [], next: null };
  }
}

export function sweepEventStore(opts: { maxAgeMs?: number; maxRows?: number } = {}): number {
  if (!db) return 0;
  const maxAgeMs = opts.maxAgeMs ?? RETENTION_MAX_AGE_MS;
  const maxRows = opts.maxRows ?? RETENTION_MAX_ROWS;
  try {
    let deleted = db.prepare("DELETE FROM events WHERE expires_at IS NOT NULL AND expires_at <= ?").run(Date.now()).changes;
    deleted += db.prepare("DELETE FROM events WHERE ts < ?").run(Date.now() - maxAgeMs).changes;
    // Row at OFFSET maxRows (newest-first) is the first over the cap; NULL subselect (under cap) deletes nothing.
    deleted += db
      .prepare("DELETE FROM events WHERE id <= (SELECT id FROM events ORDER BY id DESC LIMIT 1 OFFSET ?)")
      .run(maxRows).changes;
    return deleted;
  } catch (e) {
    process.stderr.write(`[events] event sweep failed: ${e}\n`);
    return 0;
  }
}

export function closeEventStoreForTest(): void {
  db?.close();
  db = null;
}
```

```ts
import { insertEvent, type EventRecord } from "./eventStore.js";
import { broadcast } from "./sse.js";

export const PLATFORM_NS = "_platform";
// Namespaces: an app id, or an underscore-prefixed internal namespace (_platform,
// _manager, _dashboard) — the app-id grammar has no underscore, so the two can never
// collide and no reserved-word check exists anywhere (spec §2).
export const NS_RE = /^_?[a-z0-9-]+$/;
export const TYPE_RE = /^[a-z0-9-]+$/;
export const PAYLOAD_MAX_BYTES = 8 * 1024;
export const TTL_MAX_S = 30 * 24 * 60 * 60;
// Change-feed events (kv/file-store) are the bus's noisiest tenant — a service-set
// shorter ttl keeps the backed-up file lean (durable ≠ forever, spec §4).
export const CHANGE_FEED_TTL_S = 7 * 24 * 60 * 60;

export interface EmitInput {
  ns: string;
  source: string;
  type: string;
  payload?: Record<string, unknown>;
  ttl?: number; // seconds
}

// The one emission path (spec §4): persist, then stream live over the shared SSE
// transport. One wire name ("event") for the whole bus — EventSource has no catch-all
// listener, so generic consumers filter on the envelope's `type`. Insert failure still
// broadcasts (id 0): the gap is history, never delivery. Never throws into its caller.
export function emitEvent(e: EmitInput): EventRecord | null {
  if (!NS_RE.test(e.ns) || !NS_RE.test(e.source) || !TYPE_RE.test(e.type)) return null;
  if (e.payload && JSON.stringify(e.payload).length > PAYLOAD_MAX_BYTES) return null;
  if (e.ttl != null && (!Number.isInteger(e.ttl) || e.ttl <= 0 || e.ttl > TTL_MAX_S)) return null;
  const record = insertEvent(e) ?? {
    id: 0,
    ts: Date.now(),
    ns: e.ns,
    source: e.source,
    type: e.type,
    payload: e.payload ?? null,
  };
  broadcast("event", record, e.ns);
  return record;
}
```

import { Hono, type MiddlewareHandler } from "hono";
import { zValidator } from "@hono/zod-validator";
import { z } from "zod";
import { isValidAppId } from "../registry.js";
import { validationHook } from "../validation.js";
import { emitEvent, PAYLOAD_MAX_BYTES, TTL_MAX_S, TYPE_RE } from "../events.js";
import { queryEvents } from "../eventStore.js";

export const CATALOG_NAME = "event-store";

export type EventsEnv = { Variables: { appId: string } };

// Applied by the parent router on /apps/:appId/event-store/* — validates the app id.
// No reserved-id check: internal namespaces are underscore-prefixed, outside this grammar.
export function withEvents(): MiddlewareHandler<EventsEnv> {
  return async (c, next) => {
    const appId = c.req.param("appId");
    if (!appId || !isValidAppId(appId)) return c.json({ error: "invalid app id" }, 400);
    c.set("appId", appId);
    await next();
  };
}

const emitBody = z
  .object({
    type: z.string().max(128).regex(TYPE_RE, "must match ^[a-z0-9-]+$"),
    payload: z.record(z.string(), z.unknown()).optional(),
    ttl: z.number().int().positive().max(TTL_MAX_S).optional(),
  })
  .refine((b) => b.payload === undefined || JSON.stringify(b.payload).length <= PAYLOAD_MAX_BYTES, {
    message: "payload too large (8 KB max)",
    path: ["payload"],
  });

// Shared by the app-scoped GET and (extended with `ns`) the global /api/events/history.
export const eventsQuery = z.object({
  type: z.string().optional(),
  after: z.coerce.number().int().nonnegative().optional(),
  before: z.coerce.number().int().positive().optional(),
  limit: z.coerce.number().optional(),
});

// Chained style is normative — it is what makes hc route-type inference work.
export const eventRoutes = new Hono<EventsEnv>()
  .onError((err, c) => c.json({ error: err instanceof Error ? err.message : String(err) }, 400))
  .post("/", zValidator("json", emitBody, validationHook), (c) => {
    const { type, payload, ttl } = c.req.valid("json");
    // ns = source = the app's own id — attribution can't be forged by construction.
    const record = emitEvent({ ns: c.var.appId, source: c.var.appId, type, payload, ttl });
    if (!record) return c.json({ error: "invalid event" }, 400);
    return c.json(record, 201);
  })
  .get("/", zValidator("query", eventsQuery, validationHook), (c) => {
    const { type, after, before, limit } = c.req.valid("query");
    return c.json(queryEvents({ ns: c.var.appId, type, after, before, limit }));
  });

export type EventRoutes = typeof eventRoutes;
```

  id: number;
  ts: number;
  ns: string;
  source: string;
  type: string;
  payload: Record<string, unknown> | null;
}

const INTERNAL_NS = ["_platform", "_dashboard"] as const;
const MAX_LIVE_ROWS = 500;
const MAX_ROWS = 1000;

export const Route = createFileRoute("/events")({
  validateSearch: (s: Record<string, unknown>): { ns?: string } =>
    typeof s.ns === "string" && s.ns ? { ns: s.ns } : {},
  component: EventsView,
});

function Row({ r }: { r: EventRecord }) {
  const [open, setOpen] = useState(false);
  const hasPayload = r.payload && Object.keys(r.payload).length > 0;
  return (
    <div className="border-b py-1.5 text-sm">
      <button
        className="flex w-full items-baseline gap-2 text-left"
        onClick={() => hasPayload && setOpen((o) => !o)}
      >
        <span className="shrink-0 tabular-nums text-muted-foreground">
          {new Date(r.ts).toLocaleTimeString()}
        </span>
        <Badge variant="secondary">{r.type}</Badge>
        <span className="shrink-0 text-muted-foreground">
          {r.ns}{r.source !== r.ns ? `·${r.source}` : ""}
        </span>
        <span className="truncate text-muted-foreground">
          {hasPayload ? JSON.stringify(r.payload) : ""}
        </span>
      </button>
      {open && hasPayload && (
        <pre className="mt-1 overflow-auto rounded bg-muted p-2 text-xs">
          {JSON.stringify(r.payload, null, 2)}
        </pre>
      )}
    </div>
  );
}

function EventsView() {
  const { ns } = Route.useSearch();
  const navigate = Route.useNavigate();
  const [apps, setApps] = useState<{ appId: string; name: string }[]>([]);
  const [type, setType] = useState("");
  const [q, setQ] = useState("");
  const [records, setRecords] = useState<EventRecord[] | null>(null);
  const [next, setNext] = useState<number | null>(null);
  const [debounced, setDebounced] = useState({ type: "", q: "" });

  useEffect(() => {
    const t = setTimeout(() => setDebounced({ type, q }), 250);
    return () => clearTimeout(t);
  }, [type, q]);

  const filterQuery = useMemo(() => {
    const query = new URLSearchParams({ limit: "200" });
    if (ns) query.set("ns", ns);
    if (debounced.type) query.set("type", debounced.type);
    return query;
  }, [ns, debounced.type]);

  // q is client-side (type + payload text) — the history endpoint has no q param.
  const filtersRef = useRef({ ns, type: debounced.type, q: debounced.q });
  filtersRef.current = { ns, type: debounced.type, q: debounced.q };
  const matchesQ = (r: EventRecord, needle: string) =>
    !needle ||
    r.type.includes(needle.toLowerCase()) ||
    (r.payload !== null && JSON.stringify(r.payload).toLowerCase().includes(needle.toLowerCase()));

  const pendingRef = useRef<EventRecord[]>([]);
  const hasRecordsRef = useRef(false);

  useEffect(() => {
    let cancelled = false;
    pendingRef.current = [];
    hasRecordsRef.current = false;
    setRecords(null);
    void fetch(`/api/events/history?${filterQuery}`)
      .then((r) => r.json())
      .then((d: { records: EventRecord[]; next: number | null }) => {
        if (cancelled) return;
        const pending = pendingRef.current.filter(
          (p) => p.id === 0 || !d.records.some((r) => r.id === p.id),
        );
        pendingRef.current = [];
        setRecords([...pending.slice().reverse(), ...d.records].slice(0, MAX_LIVE_ROWS));
        hasRecordsRef.current = true;
        setNext(d.next);
      });
    return () => { cancelled = true; };
  }, [filterQuery]);

  useEffect(() => {
    const es = new EventSource("/api/events");
    es.addEventListener("event", (e) => {
      const r = JSON.parse((e as MessageEvent).data) as EventRecord;
      const { ns, type, q } = filtersRef.current;
      if ((ns && r.ns !== ns) || (type && r.type !== type) || !matchesQ(r, q)) return;
      if (!hasRecordsRef.current) {
        pendingRef.current.push(r);
        return;
      }
      setRecords((rs) =>
        rs && !(r.id !== 0 && rs.some((x) => x.id === r.id))
          ? [r, ...rs].slice(0, Math.max(MAX_LIVE_ROWS, rs.length))
          : rs
      );
    });
    return () => es.close();
  }, []);

  useEffect(() => {
    void fetch("/api/apps").then((r) => r.json()).then(setApps);
  }, []);

  async function loadMore() {
    if (next == null) return;
    const bottom = [...records ?? []].reverse().find((r) => r.id !== 0)?.id ?? next;
    const query = new URLSearchParams(filterQuery);
    query.set("before", String(bottom));
    const d = (await (await fetch(`/api/events/history?${query}`)).json()) as { records: EventRecord[]; next: number | null };
    setRecords((rs) => [...(rs ?? []), ...d.records]);
    setNext(d.next);
  }

  const shown = (records ?? []).filter((r) => matchesQ(r, debounced.q));
  const setNs = (value?: string) => void navigate({ search: value ? { ns: value } : {} });

  return (
    <main className="mx-auto max-w-4xl p-8">
      <div className="mb-6 flex items-center justify-between">
        <h1 className="text-2xl font-semibold">Events</h1>
        <Link to="/" className="text-sm text-muted-foreground hover:underline">← Apps</Link>
      </div>
      <div className="mb-4 flex flex-wrap items-center gap-2">
        <select
          className="h-8 rounded-md border bg-background px-2 text-sm"
          value={ns ?? ""}
          onChange={(e) => setNs(e.target.value || undefined)}
        >
          <option value="">All namespaces</option>
          {INTERNAL_NS.map((n) => (
            <option key={n} value={n}>{n}</option>
          ))}
          {apps.map((a) => (
            <option key={a.appId} value={a.appId}>{a.appId}</option>
          ))}
        </select>
        <input
          className="h-8 w-48 rounded-md border bg-background px-2 text-sm"
          placeholder="Type (exact)…"
          value={type}
          onChange={(e) => setType(e.target.value)}
        />
        <input
          className="h-8 flex-1 rounded-md border bg-background px-2 text-sm"
          placeholder="Search payloads…"
          value={q}
          onChange={(e) => setQ(e.target.value)}
        />
      </div>
      {records === null ? (
        <Skeleton className="h-32" />
      ) : shown.length === 0 ? (
        <Card>
          <CardHeader>
            <CardTitle>No events</CardTitle>
          </CardHeader>
        </Card>
      ) : (
        <div>
          {shown.map((r) => (
            <Row key={r.id === 0 ? `${r.ts}-${r.type}` : r.id} r={r} />
          ))}
          {next != null && shown.length < MAX_ROWS && (
            <Button variant="outline" size="sm" className="mt-3" onClick={() => void loadMore()}>
              Load more
            </Button>
          )}
        </div>
      )}
    </main>
  );
}
```

export async function fetchEvents(
  base: string,
  params: { appId?: string; type?: string; after?: number; limit?: number } = {}
) {
  const query = new URLSearchParams();
  if (params.appId) query.set("ns", params.appId);
  if (params.type) query.set("type", params.type);
  if (params.after != null) query.set("after", String(params.after));
  if (params.limit != null) query.set("limit", String(params.limit));
  const qs = query.toString();
  const r = await fetch(`${base}/api/events/history${qs ? `?${qs}` : ""}`);
  if (!r.ok) throw new Error(`events fetch failed: ${r.status}`);
  return r.json();
}

```markdown
**Event**:
A durable message on the platform's event bus that drives business logic: the platform announcing an app became ready, an app announcing an export finished, a task announcing a detected change. Every event is addressed (`ns` — whose stream it belongs to) and attributed (`source` — who emitted it), persisted to the event-store, and delivered live over SSE. Events are never the system of record: precious facts belong in the emitting app's own stores — the event announces and triggers (`docs/specs/2026-07-07-events-design.md`).
_Avoid_: message, signal, notification

**Events**:
The platform-wide append-only event log (the event-store service), reached through the SDK as the `events` handle (`emit`/`watch`/`list`). One sqlite log at `data/_platform/events.sqlite` (precious — in the Backup tree), monotonic row id as the offset, retained 30 days / 50k records (change-feed events 7 days), viewable in the dashboard Events view and over MCP (`lodekit_events`).
_Avoid_: message queue, broker, SSE (that's the transport)

**Internal namespace**:
An underscore-prefixed id (`_platform`, `_manager`, `_dashboard`) naming a platform citizen rather than an app. The app-id grammar has no underscore, so internal namespaces can never collide with an app id — no reserved-word list, no enforcement code. Internal namespaces are first-class in the id space, on the event bus (they emit and own streams), in the data tree (`data/_platform/` holds the bus), and as the log query sentinel (`app=_platform`). They are **not** Apps — no source folder, no contract.
_Avoid_: reserved app, system app, internal app
```

## Events (event-store)

The platform event bus — durable, replayable messages that drive app behavior.
Import: `import { events } from "@lodekit/sdk"`.

- `await events.emit(type, payload?, { ttl? })` — announce something happened
  (`type` matches `^[a-z0-9-]+$`; payload is a small JSON object — identity, not blobs).
  Works in server functions and the browser; returns the stored event with its `id` offset.
- `events.watch({ type? }, cb)` — client-only live subscription (keep it in `useEffect`).
  The canonical live-data pattern:
  `events.watch({ type: "kv-store-change" }, () => queryClient.invalidateQueries({ queryKey: ["kv"] }))`
  — this replaces the removed `kv.watch`/`files.watch`.
- `await events.list({ type?, after?, limit? })` — replay the app's stream (includes
  platform events about the app: `building`/`ready`/`error`, `server-state`).
- **Via MCP**: `lodekit_events` (`appId`, `type`, `after`, `limit`) reads the history —
  use it to check whether an expected event actually fired.
