## Shared definitions (used by several tasks)

(v6.3.0). Use a local clone — an existing one if the person points at it, otherwise a
fresh clone in the session scratchpad — and read files from that exact commit without
touching its working tree. Never write the clone's location into a committed file;
`$UP` below is a session variable.

```bash
UP=<local clone of obra/superpowers>   # e.g. "$SCRATCHPAD/superpowers"
[ -d "$UP" ] || git clone -q https://github.com/obra/superpowers.git "$UP"

```

**Adaptation rules** (spec D6, verbatim in `.agents/SOURCES.md` after T1): plain
statements with their reasons; no `<EXTREMELY-IMPORTANT>`/`<HARD-GATE>` blocks, iron
laws, Red-Flags or Rationalization tables, "announce the skill" mandates, or flowcharts
for judgment work (a digraph may stay where it encodes a real state machine); "the
person", never "your human partner"; house paths (`docs/specs/`, `docs/plans/`,
`.agents/internal/`), house tools (pnpm, `gh`, vitest), PR-only, our lane names
(question / research / small change / bug / feature), no `superpowers:` namespace;
prose wraps at ~90 columns.

**Frontmatter** (Claude Code skill schema): `name:` equals the directory name;
`description:` says what phase or procedure the skill carries and when to load it, two
sentences at most; `lk-release` and `lk-drain` add `disable-model-invocation: true`.

**Divergence bullets.** Every adaptation task ends by appending to
`.agents/SOURCES.md` §Divergences, under a `### lk-<name>` heading, one bullet per
change class: what was dropped and why (cite the spec decision), what was added and
why, path and register changes. Terse; this is the ledger a resync reads.
